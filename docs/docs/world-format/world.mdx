---
title: world.json
---

`world.json` identifies the world and provides its top-level presentation and initial settings.

```json
{
  "id": "9d56bc2e-83ac-4eb0-b7bf-fac48772a6ef",
  "name": "Blackwater Observatory",
  "description": "A coastal town watches a silent observatory above the cliffs.",
  "author": {"name": "Example Author", "url": "https://example.com"},
  "metadata": {"tags": ["mystery", "historical"]},
  "opening_message": [
    {"type": "narration", "text": "Rain moves in from the sea."},
    {"type": "utterance", "character": "mara", "text": "We should go before dark."}
  ],
  "alternate_openings": [{"title": "Arriving late", "text": "You reach the observatory after dark."}],
  "narration_voice": "narrator",
  "variables": {"storm_warning": false}
}
```

| Field | Requirement | Meaning |
| --- | --- | --- |
| `id` | Stable; generated if absent | World identity across folder moves |
| `name` | Required | Display name |
| `description` | Optional | Player-facing summary |
| `author.name` | Required when `author` exists | Attribution |
| `author.url` | Optional | Attribution link |
| `metadata.tags` | Optional list | Catalogue filtering and presentation |
| `opening_message` | Optional | Plain text (narration only) or ordered narration/utterance parts |
| `alternate_openings` | Optional list | Other first messages the player may choose when starting a session: `{title, text or parts, character?}`: `text` is plain narration, `parts` is the same list as `opening_message` (give one, not both); at most 30 of at most 20,000 characters; a missing title is the first words of the text |
| `start_questions` | Optional list | Questions the start dialog asks before a story begins; see below |
| `narration_voice` | Optional | Initial TTS voice for narration |
| `language` | Optional | The language new stories of this world are played in, as a tag (`en`, `zh`, `ja`, `pt-BR`; only the first part counts). Without it a story follows the interface language of the person who starts it. The person can still choose another when starting. A language that has no prompts of its own uses the English ones and tells the models to write in it |
| `preset` | Optional | Name of a preset in the person's library that sessions of this world start with unless one is chosen; see the prompt system specification |
| `lorebooks` | Optional list | Names of lorebooks in the person's library that sessions of this world start with unless the start dialog chooses others; see [lorebooks](../authoring/lorebooks) |
| `variables` | Optional object | Initial values for world-scoped variables |
| `tools` | Optional object | Optional tools switched on or off for the world's agents, by kind of agent: `{"gameMaster": {"roll_dice": false}}`. A story starts from it, and a choice made at the start is added on top. Names this version does not know are kept and have no effect |

An opening is plain text when it is only narration, and a list of parts as soon as a character speaks; both forms are accepted for the world's opening and for every alternate, and whichever is written is kept as it is. The editor and the authoring assistant can change one into the other without changing a word (the assistant's `reshape_opening` splits plain text into parts and joins narration-only parts back, and a split that does not keep the exact words is refused). The start dialog offers the alternate openings beside the world's own. An opening with a `character` (the id of a playable character) is offered only to a player who takes that character, and a start that names it for anyone else is refused; a `character` that is not a playable character of the world refuses the start with the problem. A session started from one stores it as its first finished turn like any other opening.

## Start questions

`start_questions` lets a world ask the player how the story should begin. Each question is `{id, text, options}` with 2 to 8 answers, each `{id, label, description?, effect}`. The player may leave a question unanswered, and then nothing changes.

An `effect` can change only these things, and any other key makes the world file invalid:

| Key | Effect |
| --- | --- |
| `rules` | Rules added to the story's own, up to the same limits as `rules` |
| `opening` | The alternate opening to start with, by its position in `alternate_openings` |
| `starting_time` | The local story time to start at |
| `autonomy` | `true` makes stories of this world start on the real clock with the story going on while the player is away (characters keep to their days and may write to the player); absent or `false` means it never does. The player can still turn it off for a story. |
| `clock_mode` | `simulated` or `real` |
| `tools` | Optional tool switches, as in `tools` |
| `plots` | `dormant` or `available` as a plot's starting status, by plot id |

```json
"start_questions": [{
  "id": "tone", "text": "How dark should it get?",
  "options": [
    {"id": "grim", "label": "Grim", "effect": {"rules": ["No one is spared by luck alone"], "plots": {"heist": "available"}}},
    {"id": "light", "label": "Light", "effect": {"rules": ["Nobody dies unless the player chooses it"]}}
  ]
}]
```

What the person chose elsewhere in the dialog comes first: an opening or starting time they picked, and the clock mode in their settings, win over an answer. Two answers that set the same single value differently, or the same tool or plot differently, refuse the start with the reason. An answer that names a plot the world does not have refuses it too.

In the world editor, the About page edits the questions: the id, text and answers, with fields for rules, opening, starting time and clock. Tool switches and plot states are kept as written in the file.

An utterance's `character` must name a defined character. Invalid opening parts prevent session creation. The opening is stored as the first finished chat turn without a model call.

Older export manifests and separate `author.json` files are not part of this native format.
