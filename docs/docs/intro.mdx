DSH Agentic Roleplay is a roleplaying bundle for [DeepSeek Harness](https://github.com/DeepSeek-AI/DeepSeek-Harness). A game-master agent runs the scene, while characters act through independent agents with their own goals, relationships, knowledge and memories.

The world is not a fixed dialogue tree. It supplies people, places, things, lore and possible plots; the runtime decides what happens from the player's actions and the characters' choices. Persistent session state records the consequences.

## What it provides

- editable worlds and reusable player avatars;
- autonomous characters coordinated in bounded rounds;
- directional relationships and explicit, character-specific knowledge;
- events, perceptions, beliefs and story-time memory decay;
- locations, movement, items, factions, routines, variables and triggers;
- optional portraits, scene illustrations, speech and transcription;
- a dedicated world-authoring agent whose changes require approval;
- branching, take-back and durable sessions backed by SQLite.
