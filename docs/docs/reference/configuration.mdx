## Plugin configuration

| Field | Default | Purpose |
| --- | --- | --- |
| `rootPath` | `~/dsh-roleplay` | Worlds, avatars, sessions and media |
| `sessionStorePath` | `~/.dsh/sessions` | DSH session persistence location |
| `authoringTools` | none | The tools other plugins registered for everyone (a web search, MCP servers) that each authoring assistant may use: `worldAuthoring`, `presetAuthoring`, `lorebookAuthoring` and `worldAuthor` (the helper that invents things while a story is played), each a list of tool names set to `true`. An assistant has none that is not listed; the session doctor never has any. Edited under Settings, Role Play, Tools for the authoring assistants |
| `catalogues` | none | Catalogues to browse and install worlds from: a list of `name`, `baseUrl` (the API root) and `apiKeyRef` (optional; the credential in DSH's credential store that holds the API key, by default made from the name). A key written as `apiKey` text by 0.3 is still read when the store has none, and removed when the settings are saved. Edited under Settings, Role Play, Catalogues |
| `catalogueMaxBytes` | 256 MiB | Most a downloaded world may be, compressed and again unpacked |
| `catalogueTrashDays` | 30 | Days the files an update replaced stay in `.trash/worlds/` before they are deleted; 0 keeps them for good |
| `importMaxUploadBytes` | 100 MiB | Character-card upload limit |
| `importConcurrency` | 4 | Concurrent import model calls |
| `importReasoning` | empty | Import-agent reasoning level |
| `childReasoning` | empty | Default reasoning level for roleplay child agents |
| `importMaxTokens` | 16000 | Import request output limit |
| `importTemperature` | 0.2 | Import sampling temperature |

## Session defaults

| Setting | Default | Meaning |
| --- | --- | --- |
| `maxRounds` | 3 | Character rounds per player message |
| `maxCharacters` | 4 | Characters activated in one round |
| `memory.flaky` | `true` | Imperfect perception and story-time fading |
| `memory.recall` | 12 | Memories supplied per activation |
| `memory.lookup` | `true` | Character recall tool |
| `memory.lookupCalls` | 5 | Most memory look-ups per character decision |
| `memory.verify` | `true` | Keeper reads edits back |
| `memory.backlogRounds` | 6 | Forced keeper threshold |
| `memory.overRetrieve` | 4 | Candidate multiplier before final choice |
| `memory.diversity` | 0.3 | How much a repeat of an already recalled memory counts against it (0 to 1) |
| `memory.associate` | 2 | Most extra memories that come to mind with a matched one (strong tie, enough importance) |
| `memory.foldedFade` | 0.5 | Retention multiplier for a perception after a belief rests on it; 1 leaves retention unchanged |
| `reflection.auto` | `true` | Characters sort what they took in into beliefs by themselves |
| `reflection.everyTurns` | 20 | Reflect after this many turns since the last time; 0 turns it off |
| `reflection.onSceneChange` | `true` | Also reflect when your character has gone elsewhere or `sceneDays` have passed |
| `reflection.sceneDays` | 1 | Days of story time that count as a change of scene; 0 turns that off |
| `reflection.minTurns` | 5 | Fewest turns between two automatic reflections |
| `reflection.perRun` | 3 | Most characters one automatic reflection takes up |
| `reflection.minNew` | 4 | New perceptions a character needs to be taken up (a pass you start takes one) |
| `context.limitTokens` | 0 | Explicit fold limit; zero follows model metadata |
| `context.limitRatio` | 0.6 | Share of model context used as the limit |
| `context.retainRatio` | 0.5 | Verbatim share retained after folding |
| `context.shortTermTokens` | 1500 | Short-term account target |
| `context.longTermTokens` | 2500 | Long-term account target |
| `authoring.enabled` | `true` | Allow necessary world growth |
| `authoring.perTurn` | 2 | New authored characters/places per turn |
| `authoring.thingsPerTurn` | 4 | Things the GM may introduce directly |
| `clock.mode` | `simulated` | Story-time mode |
| `clock.roundSeconds` | 30 | Default round duration |
| `offstage.perTurn` | 2 | Due off-stage characters processed per turn |
| `offstage.perCharacter` | 1 | Times one character is asked per turn |
| `offstage.summary` | `true` | Off-stage characters also say in a line what happened (same request), shown as the *Meanwhile* card |
| `models.characters`, `models.background`, `models.records`, `models.suggestions`, `models.authoring` | empty | Model of that kind of helper as `provider/model`; empty uses the chat's own (`background` is for background-tier characters and falls back to `characters`) |
| `sampling.topP`, `sampling.topK`, `sampling.minP`, `sampling.frequencyPenalty`, `sampling.presencePenalty`, `sampling.repetitionPenalty` | 1, 0, 0, 0, 0, 1 | Controls beyond temperature for the game master's and the characters' requests; the default of each leaves the choice to the model's server and is not sent. A world or preset can suggest them for one story |
| `sampling.maxTokens`, `sampling.shortMaxTokens`, `sampling.headroom` | 8000, 2000, 2 | Ceilings on what one helper request may produce; the short one is for characters and suggestions, whose answers have declared sizes: they may produce `headroom` times the estimate of their answer, never more than the ceiling (settings file only) |
| `diagnostics.keepRuns` | `false` | Keep what each helper run was told and did (its instructions, what it was asked, its tool calls and result, and for a character what it was reminded of and why), for the latest 60 runs; shown in the activity list of Chat settings |
| `interface.pack` | empty | The interface pack to use: empty is the story's first, `none` is no pack, a name picks one |
| `rewind.keepSnapshots` | 30 | Recent state snapshots |
| `preview.enabled` | `true` | Show an early scene preview |
| `dice.visibility` | `card` | `card` shows what was rolled in a collapsed card under the narration, `hidden` shows nothing |
| `tools` | none chosen | Optional tools by kind of agent (`gameMaster`, `characters`, `records`) and tool name, `true` or `false`; unknown names are kept and ignored |
| `suggestions.count` | 3 | Suggested next actions |
| `images.mode` | `manual` | `off`, `manual` or `every-turn` |
| `images.references` | `prefer-reference` | Reference-image policy |
| `images.highRes` | `false` | Render each picture again larger from its first result when the image service can |
| `images.reuse` | `true` | Search existing pictures first |
| `images.interpret` | `true` | Describe uploaded pictures |

The settings UI supplies current numeric bounds. Unknown fields are rejected. Provider-specific embedding options are stored under `embedding.options`.
