---
title: 阵营与设定资料
---

阵营位于 `factions/<folder>/faction.json`，可以表示机构、家族、运动或松散联盟。它可定义简介、描述、价值观、结构、公开与内部状态、目标、成员和指向其他阵营的关系。

角色可以属于零个或多个阵营。成员关系拥有自己的职务、等级和状态。阵营目标属于阵营本身，不应在每个成员上重复。

设定资料保存不适合表示成实体或事件的规范事实。每条资料有稳定键、标题、类型、摘要、正文、主题、相关条目和可选来源。

规范资料不会自动成为所有角色的知识，除非条目另有说明。条目的 `scope` 是 `listed`（世界自己的文件里的默认值）时，持有 `knowledge.lore` 边的角色，或写在条目 `known_by` 里的角色（世界中角色的 id、名字或别名）才能获得它；`scope` 为 `everyone` 的条目是每个角色都能回忆的常识，此时不允许有 `known_by`。GM 可以搜索完整资料库；角色的回忆限于它知道的条目。来自[世界书](../authoring/lorebooks)的条目除非另有说明，都是 `everyone`。可被独立获知的事实应拆成不同条目，并关联涉及的角色、地点、物品或阵营。
