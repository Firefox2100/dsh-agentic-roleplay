---
title: 地点与物品
---

地点位于 `locations/<folder>/location.json`。`parent` 只表示包含关系；`exits` 才表示可移动路径。非单向出口会自动建立反向路径，可用 `back_description` 指定反向描述。出口状态为 `open`、`locked` 或 `blocked`，上锁出口可列出 `opened_by` 物品 ID。

地点特征是故事可寻址的组成部分，ID 只需在该地点内唯一。纯装饰应留在地点描述中，而不是全部建成特征。

物品位于 `items/<folder>/item.json`，可定义描述与视觉身份、数量、状态、是否唯一或隐藏、初始持有者或地点、所有者、容器状态、穿戴槽和变量。

只有身份、持有、状态或用途会影响故事的对象才应建成物品。固定布景更适合作为地点描述或特征。游玩中的位置保存在会话数据库；文件只描述初始安排。
