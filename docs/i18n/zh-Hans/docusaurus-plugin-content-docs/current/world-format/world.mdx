---
title: world.json
---

`world.json` 提供世界的稳定 `id`、必填 `name`、可选 `description`、作者、`metadata.tags`、开场消息、旁白声音和世界级变量初值。

```json
{
  "id": "9d56bc2e-83ac-4eb0-b7bf-fac48772a6ef",
  "name": "黑水镇天文台",
  "description": "海边小镇仰望着悬崖上沉默的天文台。",
  "author": {"name": "示例作者"},
  "metadata": {"tags": ["悬疑", "历史"]},
  "opening_message": [
    {"type": "narration", "text": "海上飘来雨云。"},
    {"type": "utterance", "character": "mara", "text": "我们得在天黑前走。"}
  ]
}
```

开场发言中的 `character` 必须引用已定义角色。开场作为第一回合直接写入对话，不调用模型。旧导出格式的 `manifest.json` 和独立 `author.json` 不属于当前原生格式。

可选的 `alternate_openings` 是其他可选开场，每项为 `{title, text, character?}`（纯叙述，至多 30 个、每个至多 20000 字符；缺省标题取正文开头几个字）。开始对话框会把它们与世界自己的开场并列提供。带有 `character`（某个可扮演角色的 id）的开场只提供给扮演该角色的玩家，为其他角色指定它的开始会被拒绝；`character` 不是该世界可扮演角色时，开始会被拒绝并给出问题。

可选的 `start_questions` 让世界在故事开始前向玩家提问。每个问题是 `{id, text, options}`，有 2 到 8 个答案，每个答案为 `{id, label, description?, effect}`。玩家可以不回答，这时什么都不会改变。

`effect` 只能改变下面这些内容，出现其他键会使世界文件无效：

| 键 | 作用 |
| --- | --- |
| `rules` | 加入故事自己规则的规则，上限与 `rules` 相同 |
| `opening` | 使用哪个备用开场，按其在 `alternate_openings` 中的位置 |
| `starting_time` | 故事开始的本地时间 |
| `autonomy` | 为 `true` 时，这个世界的故事以真实时钟开始，并在玩家不在时继续进行（角色按各自日程行事，也可能给玩家写消息）；缺省或为 `false` 则从不如此。玩家仍可为自己的故事关闭。 |
| `clock_mode` | `simulated` 或 `real` |
| `tools` | 可选工具开关，写法同 `tools` |
| `plots` | 按剧情 id 设定其起始状态为 `dormant` 或 `available` |

```json
"start_questions": [{
  "id": "tone", "text": "故事要多黑暗？",
  "options": [
    {"id": "grim", "label": "严酷", "effect": {"rules": ["不会仅凭运气让任何人幸免"], "plots": {"heist": "available"}}},
    {"id": "light", "label": "轻松", "effect": {"rules": ["除非玩家自己选择，否则没有人会死"]}}
  ]
}]
```

世界编辑器的“关于”页可以编辑这些问题：标识、问题文字和各个回答，并提供规则、开场、起始时间和时钟的字段。工具开关和剧情线状态按文件中所写保留。

玩家在对话框里其他地方所做的选择优先：他们选的开场或开始时间，以及其设置里的时钟模式，都会压过答案。两个答案对同一个单值设置、同一个工具或同一个剧情给出不同结果时，开始会被拒绝并说明原因；答案提到世界里没有的剧情时同样被拒绝。

可选的 `language` 是该世界新故事默认使用的语言，写成语言标记（`en`、`zh`、`ja`、`pt-BR`，只看第一段）。没有它时，故事使用开始者的界面语言；开始时仍可另选。没有专属提示词的语言会使用英文提示词，并要求模型用该语言写作。

可选的 `preset` 是资料库中预设的名称：除非开始时另行选择，该世界的会话使用这个预设来写作（见提示词系统规范）。

可选的 `lorebooks` 是资料库中世界书的名称列表：除非开始对话框另行选择，该世界的会话以这些世界书开始（见[世界书](../authoring/lorebooks)）。

可选的 `tools` 字段给出世界的智能体的可选工具开关，按智能体类别分组，例如 `{"gameMaster": {"roll_dice": false}}`。故事以它为起点，开始时所做的选择叠加在其上。此版本不认识的名字会被保留，但不起作用。
