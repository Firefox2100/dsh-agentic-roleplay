---
title: 提示词与媒体
---

世界提示词位于 `prompts/<language>/<group>/<name>.md`，会话也可保存覆盖。解析时优先采用最具体的文件，并按配置语言和内置英文默认值回退。

提示词文件只保存稳定指令，不保存当前故事状态。场景、角色和记录由运行时变量注入。稳定内容应放在前部以保留模型前缀缓存。

图片路径包括全局身份的 `images/global/<id>/reference.png`、本地实体参考图、按时间线节点编号的 `images/scenes/`，以及上传图片的 `images/library/`。生成 PNG 携带用途、来源、模型、提示和主题等元数据，必要时使用伴随文件。

世界封面当前通过 `cover_media_id` 和 `media/manifest.jsonl` 解析。缺失或不安全的封面会报告问题，但不会隐藏其他方面有效的世界。
