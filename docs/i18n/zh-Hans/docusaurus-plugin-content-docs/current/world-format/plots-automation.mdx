---
title: 剧情、变量与触发器
---

`plots.json` 描述可选故事结构。剧情由前提、压力策略和多个节拍组成。节拍是可被引入或调整的发展机会，不是强迫 GM 达成结果的命令。应描述忽略问题会怎样、哪些迹象可提前出现，以及什么结果会关闭或改变剧情。

节奏系统只在故事缺少方向时选择少量推动，尊重冷却和明确拒绝，也不会同时推进所有剧情。

`variables.json` 声明供条件与工具使用的类型化值，实体或世界文件可提供初值。关系、知识、位置和物品状态已有专门模型，不应重复编码成变量。

`triggers.json` 表示条件满足时必须确定发生的反应，包含条件、效果、重复规则和可选时间。触发器修改会话状态，不修改世界文件。
