---
title: 格式概览
---

一个世界必须正好位于 `<root>/worlds/` 下一层，并包含 `world.json`。可选的 `calendar.json` 定义自定义节日和季节所依据的半球，可选的 `dice.json` 定义用来裁定不确定尝试的[骰子检定](./dice)。角色、地点、物品和阵营分别放在对应目录的子文件夹中；设定资料、剧情、变量、触发器、提示词和图片也保存在世界目录内。

JSON 字段使用 `snake_case`。`world.json.id` 是跨文件夹移动仍保持不变的世界身份；缺失时目录扫描会生成 UUID 并写回。重复世界 ID 会被拒绝。实体 ID 在各自类型内唯一，引用使用 ID 而不是名称或文件夹名。

世界文件保存定义与 `start` 初始状态。会话开始时复制到数据库，游玩中的变化不会写回源世界。

读取器会收集带路径的全部问题。损坏引用、无效角色或开场消息会阻止开始会话，避免生成部分导入的状态。媒体路径不得通过符号链接或相对路径逃出世界目录。
