---
title: 架构与软件包
---

| 软件包 | 职责 |
| --- | --- |
| `dsh-agentic-roleplay` | 可安装套件与配置补丁 |
| `@dsh-agentic-roleplay/core` | UI、文件世界、编排、智能体、提示词、媒体和 HTTP API |
| `@dsh-agentic-roleplay/state` | 独立 DSH 状态服务、SQLite 仓库、回忆和记录工具 |
| `dsh-roleplay-model` | 以源码共享并打包进消费者的私有规范模型 |

核心插件依赖 Cordis 的 `roleplayState` 服务，而不是直接打开数据库。主机端验证和修改文件与数据库；浏览器端通过认证的 `/roleplay-api` 和 DSH 插槽工作。共享模块只放传输类型、ID 与纯路径规则。

世界数据以文件系统为准；会话故事状态以事务形式保存在每会话一个 SQLite 数据库中。会话配置保留为可读的 `settings.json`，图片保留为自描述普通文件。

新增故事模型能力时，应同时更新规范模型、数据库与仓库、记录编辑格式、读取工具、记录员提示、回忆或注入、创作、编辑器和文档。
