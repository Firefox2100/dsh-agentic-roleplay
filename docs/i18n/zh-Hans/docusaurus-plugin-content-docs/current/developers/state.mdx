---
title: 使用 @dsh-agentic-roleplay/state
---

`@dsh-agentic-roleplay/state` 是提供 `ctx.roleplayState` 的独立 DSH 插件。消费者应通过 Cordis 注入并使用会话存储与仓库接口，不要直接操作 SQLite。

```ts
import type {} from '@dsh-agentic-roleplay/state'
export const inject = ['roleplayState']
```

通过服务创建会话，确保目录、模式和元数据一致初始化。相关修改应放在一个事务中。仓库错误会区分记录不存在、输入无效和冲突，例如尝试修改已封存事件。

记录 API 可读取适合模型的视图，并验证事件、感知、信念、状态、移动、物品、关系和知识等编辑。信念包含确信程度，以及指向支持或反驳它的感知的明确关联。只有记录员完成并验证提交后才封存事件。

会话元数据还可保存世界日历。日程与触发器辅助函数在判断日期、季节和节日规则时会读取它；外部消费者应使用该包导出的日历函数，不要自行解释 `on` 标记。

该包重新导出规范模型类型，外部插件不需要依赖私有模型包。
