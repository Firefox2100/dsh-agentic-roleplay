---
title: 目录
---

**目录**页用来浏览 [Roleplay Catalogue](https://github.com/Firefox2100/roleplay-catalogue) 中的世界，并把它们安装成你自己的世界。你可以添加多个目录，也可以直接用世界压缩包的地址安装。

## 设置目录

打开**设置 → 角色扮演 → 目录**，选择**添加目录**：

- **名称**：你给它起的名字，彼此不能重复。
- **API 地址**：目录的 API 根地址，例如 `https://catalogue.example/api`；如果目录的 API 没有前缀，则如 `http://localhost:9798`。必须是不含用户名、查询参数和片段的网址。
- **API 密钥**（可选）：在目录中创建的密钥。填写后，页面还会显示该密钥有权读取的私有世界；不填则只显示公开世界。

保存时，列表会写入当前配置档（profile）的配置中，密钥以明文保存在其中；设置表单会遮住它，但编辑期间它会保存在浏览器中。请使用专门为此创建、权限尽量小的密钥，并保护好配置文件。

## 浏览与安装

页面列出所选目录中已发布的世界，可搜索，也可按最新或热门排序。工具栏下方一行会说明是否正在使用你的密钥。在设置中保存新的密钥（或移除密钥）后，页面会自动更新，私有世界随之出现或消失，无需重新加载。

选择一个世界可以查看它的简介、标签和发布版本。**安装**会下载所选版本，用目录公布的校验和核对，然后把它加入你的世界。之后你可以像对待任何世界一样游玩或编辑它；它是一份副本，不会再联系目录。如果文件夹名与已有世界相同，新世界会使用带编号的文件夹。从某个发布版本安装的世界会记住它来自哪个版本，因此目录有新版本时页面可以提示你。

世界可能附带界面包。界面包会在游玩时、在容纳所有界面包的沙盒中运行自己的脚本。页面会告诉你带来了哪些界面包；如果不了解作者，请先查看。

## 更新已安装的世界

如果目录里有你已安装世界的新版本，页面会在网格上方列出。选择它并点击**更新**。新版本会在原来的文件夹里替换这个世界，所以你的会话照常可用；你之前的文件会移到角色扮演根目录的 `.trash/worlds/`，而不是被删除。

如果你在安装之后修改过这个世界（增加、编辑或删除了任何文件），页面会告诉你，列出有差异的文件，并让你选择：

- **覆盖我的版本**：用发布版本替换你的版本。你的版本仍保留在回收文件夹中。
- **都保留**：把发布版本另装为一个名为“(copy)”的独立世界，拥有自己的标识，不动你的世界。这份副本与目录没有关联，因此不会提示更新。

没有版本记录的世界（在记录版本之前安装的，或手动复制来的）会遇到同样的询问，因为无法判断你是否修改过。只要你已经有某个世界，随时都可以选择**另装一份副本**。

## 角色卡

**角色卡**标签页列出目录中的 SillyTavern 角色卡。**转换为世界**会用目录的密钥下载角色卡，并启动常规的[角色卡导入](../authoring/avatars-import)：创建一个新世界，由它的创作对话转换这张卡，然后打开该对话。

角色卡永远不会更新或替换已有的世界。转换由一个会自行做出选择的智能体完成，同一张卡转换两次会得到不同的世界，覆盖旧的世界没有意义。再次转换一张卡总是生成一个新世界，如果你以前转换过这张卡，页面会告诉你。

## 从地址导入

**从地址导入**可以用世界 ZIP 压缩包的地址安装世界：

- 属于你添加的目录的地址，会带上该目录的密钥请求，所以密钥有权读取的私有版本也可以安装；
- 其他地址按原样获取。它必须是标准端口上的公开网址；如果需要登录，导入会失败并说明原因；
- 密钥只会发送给配置它的站点，即使下载被重定向到别处也一样。

压缩包必须只含一个带 `world.json` 的顶层文件夹。世界先写在你的世界旁边，完整后才移入，所以被拒绝的压缩包不会留下任何东西。含有链接、不安全或重复路径、加密，或超过大小上限 `catalogueMaxBytes`（解压后 256 MiB）的压缩包会被拒绝。
