---
title: 会话设置
---

高级设置可在开始会话前选择，也可在**对话设置**中修改。它们存放在会话数据库旁的 `settings.json`，并在每次使用前读取。

表单顶部的**快速预设**用深度换取速度：关闭辅助智能体推理、场景预览、记录复核、角色记忆查询、离场回合、自动反思和运行中世界扩展，并把每条玩家消息限制为最多两轮、每轮三个角色。点击按钮只会填写表单，保存或开始会话后才会生效，之后仍可逐项修改。

主要分组包括：

- **轮数：**一条玩家消息最多推进几轮，每轮最多激活几个角色。
- **记忆：**不完美记忆、召回数量、查询工具、检索范围、记录复核，以及感知被信念吸收后的淡化速度。
- **反思：**角色是否自行把见闻整理成信念，多久整理一次，场景变化是否触发，以及每次处理哪些角色。
- **决策模型：**触发条件和信念证据由语言模型、决策模型还是两者判断。这里也能开启玩家角色自主权和跳出故事检查。规则复查和隐藏背景检查只由决策服务执行，默认关闭；没有决策服务时不会运行。
- **上下文：**明确的令牌上限，或选中模型上下文窗口的比例，以及短期和长期摘要大小。
- **创作与时间：**是否允许运行中扩展世界、每回合上限、故事时钟、离场角色、派系和触发器。
- **预设与界面包：**查看故事是否仍与资料库一致，并切换、重新应用或移除预设；选择世界附带的界面包或不用界面包。
- **模型、推理与采样：**为不同辅助智能体选模型，并调整推理等级、温度和其他采样参数。
- **图片：**生成模式、参考图策略、复用、上传图片理解、说明模型和大图再渲染。
- **提供方选项：**选中的嵌入或媒体提供方声明的额外设置。

**反思**分组决定角色是否自行把见闻整理成信念、每隔多少回合整理一次、场景转换是否也触发、两次反思之间的最少回合数、每次处理多少个角色，以及角色需要多少条新见闻。

**模型**分组可为每类助手（角色、背景角色、记录员、建议作者、世界与剧情作者）分别指定 `提供方/模型`，留空则使用对话自己的模型。角色并行运行且回答简短，记录员在后台运行，这些位置用较小较快的模型通常也能胜任。

**骰子**设置决定你是否看到主持人掷出的骰子：叙述下方一张折叠的卡片，想核对时展开；或什么都不显示，保持沉浸在故事里。无论哪种，骰子都会照常掷出。以 `/roll 2d6+1 撬锁` 开头的消息可以自己掷骰，结果会作为事实告诉主持人。

**工具**设置以开关的形式决定每一类智能体（主持人、角色、记录员）可以使用哪些可选工具。选择对该类的所有智能体生效，而不是只针对某一个角色。在对话设置里它是**工具**区域，切换即保存；世界可以在编辑器里设置自己的选择，故事以其世界所说的为起点。除了主持人的骰子工具，角色的查询（`recall_my_memories`、`recall_my_known_entities`、`recall_my_lore`）和记录员的四个查询（`search_events`、`list_threads`、`list_relationships`、`list_items`）也可以关闭，让它们的请求更省；默认全部开启。记录员的 `read_records` 和 `edit_records`，以及它的地点、派系、物品、日程和变量查询，不可关闭。此版本不认识的名字会保留在文件里、也不显示，因此在工具多一些或少一些的版本之间搬运的世界仍能加载。

每一类智能体下还有一个折叠的列表，列出其他插件为所有人注册的工具（文件或命令行访问、搜索引擎之类的 MCP 服务器）。它们默认关闭，需要按智能体类别分别开启：主持人、角色（所有角色）、记录员。没有开启的智能体看不到它们，连第一次请求里也没有，因此把这类插件加载进配置并不会自动让故事里的智能体获得文件或命令行访问权。工具以其插件所拥有的权限运行，所以只开启这个智能体应该能做的事。已开启但当前没有注册的工具会被保留，但不起作用。

**会话医生**区域为这个故事打开一个独立的对话（见[会话](sessions)）：助手阅读故事记录下来的内容，找出对不上的地方，并提出修复，由你逐条批准。

**决策模型**区域显示决策服务是否可用、是哪一个，以及每个可以使用决策模型的环节当前的设置和在本故事中的表现：决策模型做出了多少次判断、因没有把握而交给语言模型多少次、因无法使用而回退多少次、两者都被询问时与语言模型的一致程度、各自平均耗时，以及最近的分歧。故事回退时，这些计数仍然保留。

**反思**区域显示角色们上一次整理记忆的时间、每个角色的结果（新增、修改、放下的信念数），以及失败时的原因。**立即反思**会马上开始一次整理，自动反思关闭时也可使用；它在后台进行，回合进行中或已有一次整理在运行时无法开始。

其上方的**世界摆到故事面前的东西**列出触发器最近送出的内容：交给游戏主持人的节拍和交给角色的提示，各自标为等待中、已采用（主持人织入了节拍，或角色据提示行动）或已失效（期限内无人理会）。可用来查看某个触发器是否产生了效果。

标签页底部的**助手最近做了什么**列出各助手最近的运行：哪个助手、用哪个模型、耗时多久、调用了几次工具，失败时还有原因，可用来查看一个慢回合的时间花在哪里。每次运行还会显示它用掉的令牌。其上方的**每回合令牌用量**按回合汇总：游戏主持人，以及为该回合工作的助手（包括回合送出之后完成的工作），并把模型服务从缓存读取的部分单独列出。数字以模型服务的报告为准，服务不报告就不显示；让故事回退会去掉不再有效的回合。不显示金额，因为模型的价格不是 DSH 所知道的。

需要知道某个助手为何那样说或写时，打开**保留助手收到的内容**（`diagnostics.keepRuns`），继续游玩，再点某次运行的**查看**：可看到它的指令、被问的内容、每次工具调用及返回，以及它提交的结果。对角色来说还会列出它被提醒了什么，以及每条记忆为何被想起：线索（人名、共有字词、地点）、字词检索与含义检索及重排序（若运行过）的得分、重要程度、过去多久以及还剩多少印象。会话文件夹中保留最近 60 次运行。其中包含角色私下所知的信息，因此不排查问题时请保持关闭。

外部编辑无效时，系统记录问题并继续使用最近一次有效设置，因此故事不会因拼写错误而中断。完整默认值见[配置参考](../reference/configuration)。

故事的叙述指令来自哪个[预设](../authoring/presets)，也在对话设置中：**预设**区域会显示故事是否仍与资料库一致，并可以切换、重新应用或取消它；开始时预设还会填入你没有设置的叙述者和角色温度。

故事使用哪个[界面包](../authoring/interface-packs)（或不用）也在对话设置中，那里有专门的一部分：它会报告问题，并可带入世界中较新的包；插件自带的 *Scene* 界面包可以在任何世界里指定使用。

过去只能在 `settings.json` 里改的设置，现在表单里都有了：主持人与辅助者的输出上限和输出余量、辅助者是否必须以工具调用作答（`sampling.tools`）、短期与长期摘要的长度，以及提示保留的回合数。无休止思考的模型会停在主持人的上限（默认 12000 token），而不是运行数分钟。

## 导入与创作助手

导入角色卡、预设或世界书，翻译世界，以及世界作者的助手，都是以小型智能体运行的。它们在整个插件范围内统一设置，而不是按故事设置：**设置 → 角色扮演 → 导入与创作助手**。修改立即生效。

- **助手思考强度：**思考的强度，须是模型提供的级别（例如 `off`）。一直思考的模型永远不会给出答案，所以导入卡住时请设为 `off`。它也适用于创作对话本身（你与之交谈的世界、预设和世界书助手），其模型须提供该级别。留空则使用下面“故事助手的思考强度”，再留空则与对话本身一致。
- **故事助手的思考强度：**对话自己的设置为空时，故事中的角色、记录员、作者和建议作者使用的级别。
- **助手使用的模型：**这些助手所用的 `provider/model`；留空则使用对话的模型。
- **温度**、**每次请求的最大 token 数**和**同时运行的助手数：**它们写作的自由度（默认取低值，因为它们是在抄写和整理）、一次回答最多多长（包括思考），以及并行运行多少个。
- **每次请求的最大 token 数**是上限：每项任务还有各自更小的、按所需答案大小定的上限；助手若把文字一直写到上限而不给出结果，会被立即停止，而不是被提醒再试。创作对话中写到上限被截断的回复，会被引导回去执行或简短总结。
- **助手的时限（分钟）：**助手超过这个时间（默认 15，0 表示不限制）仍没有结果就会被停止，该步骤会说明原因，因此失控的助手不会让导入卡上几个小时。停止对话的这一轮也会停止它们。
- **整理卡片时的决策模型：**选 `decision`，并在提供方中选好决策模型后，卡片里只是指令或说明的片段在决策模型有把握（**把握程度**，默认 0.7）时由它直接判定，不再询问语言模型；它没把握的片段或出现任何失败时，照常交给语言模型。调查结果会报告它判定了多少个片段。

助手收到的指令是数据文件夹 `prompts` 中的导入提示词，语言跟随该世界创作对话打开时所用的语言；展示给它们的每个片段的标签以及对话的标题也是如此。

**上传与下载限制**在其下方的单独一节，立即生效：角色卡、预设或世界书上传的大小上限（默认 100 MB）、目录下载的大小上限（256 MB），以及更新后被替换的文件在回收文件夹中保留的天数（30；0 表示永久保留）。
