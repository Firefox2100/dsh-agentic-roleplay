## 语音

世界或会话可设置一个旁白声音，每个角色可设置自己的声音。提供方能列出声音时可直接选择，否则可手工输入 ID；有些服务器并不通过 API 暴露声音目录。

声音属于呈现设置，不会改变角色身份、故事记录或 GM 输出的文字。世界可以提供合适的默认值，单个会话也能自行更换，而不影响从该世界创建的其他会话。

播放完整 GM 回复时，系统会分别合成旁白和每段角色发言，再按原顺序组合。角色旁的播放按钮只合成该段发言。请求可在提供方并发限制内同时运行。

语音输入使用 DSH 的语音服务。API 服务可以转录已完成的音频文件；只有选中的提供方实现独立流式接口时，才会启用实时转录。

### 选择与测试声音

- 旁白声音应在环境描述和场景转换中都保持清晰。
- 只有确实有助于区分角色时才需要不同声音；次要角色不必人人独立。
- 服务无法列出目录时，可手工填写提供方的声音 ID。
- 合成长回复前先用短句测试，不同提供方支持的选项和限制并不相同。

语音只基于最终交付的回复生成，不会朗读隐藏的角色思考。合成失败时，文字回合仍然完整，可以继续阅读或重试。

## 图片

点击肖像可生成或重新生成实体的规范参考图。场景插图可以关闭、手工请求或设置为每回合自动生成。

肖像生成属于创作操作：它更新角色、地点、物品或阵营可替换的参考图。场景生成属于游玩操作：它记录某一时间线节点上的瞬间，不会替换规范身份。

启用复用后，图片作者会先搜索现有图片，再决定采用合适的素材或生成新图。上传图片可由视觉模型解释、描述并加入可搜索图库。

参考图路径稳定且可以替换。场景图不可变，并按时间线节点编号。参见[视觉身份](../authoring/visual-identity)与[图片和上下文](../concepts/images-context)。

## 图库与复用

会话的**图库**展示生成和上传的图片及其主体、来源等元数据。复用允许图片作者在发起新生成前搜索图库，适合反复出现的房间、建立镜头及其他不应每次重新消耗生成请求的素材。

上传图片经视觉模型描述后可以参与语义搜索。没有图片理解能力时，图片仍可保存和查看，但语义复用可用的信息会更少。

## 缺少能力时

媒体功能都是可选的。没有图片、语音或转录提供方也不影响文字游玩。控件不可用时，请在**设置 → Providers**（连接）和该能力自己的服务页（活动提供方）确认相应能力不仅已配置连接，而且已经选中活动提供方。两者的区别参见[配置 AI 服务](../getting-started/ai-services)。
