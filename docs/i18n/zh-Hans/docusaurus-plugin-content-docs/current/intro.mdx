DSH Agentic Roleplay 是 [DeepSeek Harness](https://github.com/DeepSeek-AI/DeepSeek-Harness) 的智能体角色扮演套件。游戏主持人智能体负责场景，多名角色智能体依据各自的目标、关系、知识和记忆自主行动。

世界不是固定的对话树。世界卡提供人物、地点、物品、设定资料和可能的剧情；实际发展由玩家选择和角色决策共同产生，并持久保存到会话状态中。

## 主要能力

- 可编辑的世界和可复用玩家化身；
- 有边界的多轮自主角色行动；
- 有方向的关系与每个角色独立的知识；
- 事件、感知、信念和按故事时间衰减的记忆；
- 地点、移动、物品、阵营、日程、变量与触发器；
- 可选的肖像、场景插图、语音合成与语音识别；
- 需要用户批准修改的专用世界创作智能体；
- 基于 SQLite 的持久会话、回退与分支。
