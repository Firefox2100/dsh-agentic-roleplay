---
title: 回合编排
---

一条玩家消息可在最终叙述前产生多轮角色行动。GM 读取行动、场景、相关记录、节奏提示和规则，激活此刻需要做决定的角色；角色智能体依据自身有限视角返回意图、可选发言和投入程度；GM 解析结果并更新状态，随后选择下一轮或输出叙述。

高投入但失败的行动可带着第一次结果重试一次。后续轮会看到本回合之前的轮次。

GM、角色、记录员、世界作者、编年者和图片作者拥有不同提示词与工具。子智能体是一次性的，持久身份和记忆来自角色扮演状态而不是私有聊天记录。

轮数、参与角色数、工具调用和输出长度都有边界，避免自主场景无限运行。稳定人格和工具定义放在变化内容之前，以提高模型前缀缓存复用。
