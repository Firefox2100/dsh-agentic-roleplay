title: 图片与上下文
---

## 视觉连续性

规范视觉身份是稳定数据，参考图在固定路径呈现该身份。场景图则把它与当前服装、表情、行动、损伤、光照和环境结合。

把两层分开，可以防止一个戏剧性瞬间改写实体平时的外观。被雨淋湿的外套、包扎的手或烛光属于场景描述；年龄、面部结构、纹章标志或特殊物品的材质属于规范身份。

图片作者可以在生成前搜索可复用图片。搜索使用描述、主体和标签，并可选用语义向量。存在视觉模型时，上传图片会先获得描述，再进入可复用图库。

图片元数据随文件保存，因此复制或手工管理媒体库不需要同步数据库表。身份版本会标记有意的稳定变化：作者修改外观并增加版本后，旧参考图不再代表当前身份；既有场景图仍然保留为当时的不可变记录。

## 图片请求会获得什么

图片作者只组装当前图片真正需要的内容：场景构图、可见主体、稳定身份和相关的当前外观。提供方支持时还可以附带参考图。私密想法和无关世界记录无需进入图片提示词。

启用复用后，图片作者会先搜索现有媒体。合适的图库图片可以直接采用，避免重复生成，让反复出现的视觉素材保持一致。

## 对话上下文

完整对话在达到显式 token 上限或所选模型上下文窗口的一定比例之前保持原文。压缩只移除完整旧回合。

角色扮演状态和对话承担不同职责：对话保存玩家读到和说出的内容，数据库保存世界的持久事实与各角色的视角。因此，压缩可以缩短旧聊天，而不会删除以后仍需使用的事件、关系或信念。

编年智能体依据权威事件和玩家行动撰写短期摘要与较长章节，不会脱离记录反复概括已有摘要。摘要不是新的事实来源，而是根据权威记录生成的叙事桥梁。当前场景、未完成线索和检索到的记忆仍然分别放在提示词靠后的变化区域。

两次折叠之间，新内容只追加到末尾，从而提高模型前缀缓存复用。这让长篇故事保持在模型上下文窗口内，同时避免反复摘要逐渐用自己的改写取代具体事实。
