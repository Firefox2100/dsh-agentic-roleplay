---
title: 故事时间、日程与节奏
---

模拟模式中，时间依据 GM 记录的轮次时长和显式跳时前进；现实模式跟随配置时区的墙上时钟。拥有独立日期的模拟故事不能再切回现实时间。

记忆年龄、截止时间、日程和离场行动都使用故事时间，而不是回合数或现实耗时。大量回合可以只经历一分钟，一次跳时也可以跨越数日。

日程只提供角色通常所在位置与活动，承诺、中断和剧情事件都可覆盖它。回合结束后，有限数量的离场角色可处理到期承诺或截止事项。同一个约定的几个人会依次决定，后者会被告知谁已决定前来，因此碰面发生在人与人之间（设置 `offstage.joint`）。组织也会自行行动：你发送消息后，最多 `factions.perTurn` 个手握目标、且距上次决策已过 `factions.everyDays` 天故事时间的组织各自决定做一件具体的事。这会改变它们的状态与目标，并记录为一件在有人被告知之前无角色知晓的行动。

剧情为 GM 提供可选节拍与压力；触发器则保证条件成立时执行确定反应。前者可调整或推迟，后者适合作者要求每次一致发生的变化。
