---
title: 记忆、知识与关系
---

记忆层级是**回合 → 事件 → 感知 → 信念**。事件是客观且不可变的记录；感知是某个角色看到、听到、被告知或推断的版本，可以不完整或错误；信念是跨越单个事件形成的持久认识。

记录员在 GM 请求或积压达到上限时处理轮次，并可在完成前读回验证。完成后事件被封存；后续纠正应修改感知，而不是重写历史。

回忆结合显式线索、全文搜索和可选语义向量，重排序服务可精排更大的候选集。重要性、相关度、故事时间的新近程度和保留率共同决定最终内容。

关系是单向视图，没有出边表示陌生。地点、物品、出口和设定知识采用显式闭世界图，没有边就是不知道。知识边只表示能识别实体，不泄露其当前位置、所有者、内容或状态。
