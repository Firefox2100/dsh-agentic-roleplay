## 记录下来的经历

记忆从**回合**进入**事件**，再分为角色各自的**感知**，并沉淀为**信念**。

- **事件** 是客观、不可变的事情记录。
- **感知** 记录某个角色看到、听到、被告知或推断的版本，可以不完整或错误。
- **信念** 记录角色在单一事件之外形成的持久认识、确信程度，以及支持或反驳它的感知。
- **故事线索** 保留尚未解决的承诺、谜团和目标。

每个被记录的轮次会立刻留下朴素事件：每个角色的行为一条，每句台词一条，一字不差，由当时在场的人感知。记录员在 GM 请求或积压达到上限时处理轮次，并可在完成前读回验证。完成提交后，事件会被封存；后续纠正应修改感知，而不是重写历史。

这种分层避免叙述文本直接充当数据库。文字可以简洁或富有风格，持久事件仍会记录涉及人物、发生地点和实际变化。角色的感知可以遗漏或误解其中一部分，而不会改变客观记录。

### 一个小例子

假设 Elias 解锁西门，而 Mara 在楼梯上看见：

- **事件** 记录 Elias 解锁了门；
- Mara 的 **感知** 记录她看到和听到的内容；
- 建筑外的人不会仅因事件存在就自动获得感知；
- Mara 以后可能形成“钥匙属于 Elias”的 **信念**，即使钥匙其实是借来的。

之后的回忆可以把 Mara 的经历重新带回，但不会把同一段记忆授予所有角色。

## 回忆

回忆结合显式线索、全文搜索和可选语义向量。重排序提供方可以精排更大的候选集，重要性、相关度、故事时间的新近程度和保留率共同决定最终内容。

系统先取回多于最终需要的候选，再选择一小组相关且彼此有差异的记忆。共享人物、地点或强标签的关联记忆也可能被一同唤起，让一次回忆自然带出另一段经历，而不暴露无关记录。启用诊断后，运行检查器可以显示某条记忆被选择的原因；这些评分不会发送给模型。

不完美记忆会按照经过的故事时间、重要性和重复回忆程度淡化细节。重要记忆至少会以模糊形式保留。关闭此功能会得到精确回忆和准确感知。

一条感知被归纳进信念后，回忆通常优先提供信念，而不是把两条记录重复交给角色。作为依据的感知还会按 `memory.foldedFade` 更快淡化。默认值 `0.5` 会把原有保留时间缩短为一半；`1` 表示不改变。感知仍保留在记录中，也仍可作为证据引用。

记忆按故事时间计算。跳过一个月可能比同一晚进行二十个回合带来更多淡化；重要性和保留率会让关键经历保持更久。

## 反思

信念不会自己冒出来。玩了一段时间之后，**反思**会让每个角色把自上次以来接收到的见闻整理成自己的信念：新增信念、巩固或质疑已有的信念、合并重复的信念，或放下某一条。反思只使用该角色自己的感知和信念，所以不会给角色它从未接收过的东西，写下的也是角色的看法，可能是错的。

角色整理记忆之前，每条信念都会在一个单独的小请求里，与角色此后接收到的、与它有关的几件事（涉及信念所关于的人，或与信念共用词语）对照：这个看法与这些内容能否同时成立？这样发现的矛盾由引擎记为存疑：信念的把握程度降低一级，与之相对的内容保持链接。同一轮里，这条信念不会被改写或放下，新得知的内容写进新的信念。整理所提议内容中形式上的错误（引用了没有展示过的内容、不存在的信念、过长的文字、只凭一个转瞬即逝的瞬间写成的新信念）会被修正或略去，而不是被拒绝；某个角色整理不了时，其他角色仍会完成，它会在下次再试。

每条信念的确信程度为 `doubtful`、`likely` 或 `sure`。每一项反思改动都要写明支持或反驳它的感知，写入前引擎会核对这些关联：

- 新信念必须有至少两个不同回合的见闻作依据（或一个改变了故事走向的高重要度事件）。单个转瞬即逝的时刻还不算信念。
- 新建 `sure` 信念必须有至少两个不同回合的支持感知。新的支持可提高已有信念的确信程度，反驳证据可降低它；降低确信程度时必须提供一条反驳感知。存疑是单独的一步：反思写明哪条信念以及什么与之相悖，该信念的确信程度就会替它降低一级（不低于 `doubtful`），相悖的感知与它建立关联；因此不必让模型同时兼顾文字、确信程度和编号。凡是把本应放在字段里的内容（确信程度、重要性或所依据的编号）写进信念文字的，都会连同这条理由被拒绝。
- 只有在信念形成之后出现了新的见闻，或把它并入另一条保留的信念时，才修改或放下它。
- 反思只写信念，不改动也不新增任何事件，历史保持原样。

自上次反思以来过了 `reflection.everyTurns` 个回合（默认 20）时，或场景转换时（你的角色去了既不在原处、也不在原处内部或周围的地方，或故事时间过去了一天），反思会自动开始。两次自动反思之间至少间隔 `reflection.minTurns` 个回合。新见闻最多的角色先处理，最多 `reflection.perRun` 个，并且只处理至少有 `reflection.minNew` 条新感知的角色；你扮演的角色和背景角色不参与。你也可以在对话设置里点击**立即反思**手动开始，这时会处理所有有新见闻的角色。反思在后台进行，可用 `reflection.auto` 关闭。

## 关系与知识

角色关系是有方向的描述。没有从某人指向另一人的关系，表示对方仍是陌生人；在适当情况下，相遇会建立熟人关系。

地点、物品、出口和设定资料的知识采用显式闭世界图。没有边就表示不知道。知识边只说明角色能够识别该实体，不会泄露它当前的位置、持有者、内容或状态。角色导航也只使用自己已知的地图。

关系与知识回答不同问题：关系说明某人如何看待另一人；实体知识说明其是否能够识别某物；感知与信念则保存其经历过什么、由此相信什么。

因此，把事实写进世界公开描述并不等于授予所有角色相应知识。作者应把秘密交给确实知道它的人，再让游玩为其他角色创造新的感知和信念。
