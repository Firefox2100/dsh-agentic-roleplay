---
title: 故障排查
---

**世界未显示：**确认它正好位于 `worlds/` 下一层并包含可读 `world.json`，刷新列表，检查验证问题、重复 ID 和缺失 ID 是否可写回。

**会话无法开始：**所有角色都必须有效，所选角色必须可扮演，开场角色 ID 必须存在，并且 DSH 会话服务可用。

**AI 功能不可用：**在**设置 → AI Providers**确认已经选择该能力的提供方。配置连接并不等同于选择服务。图片目前要求提供方返回 PNG。

**记忆只有关键词检索：**确认嵌入服务和 sqlite-vec 可用。向量绑定模型和维度，修改后需要重建。重排序失败会自动退回原检索结果。

**没有实时转录：**当前 STT 可能只支持完整文件，没有实现独立流式接口。

**设置修改无效：**检查 `settings.json` 验证错误；运行中会继续使用最近一次有效值。

**界面包没有显示：**打开故事的**对话设置**，查看**界面包**部分。它会说明正在使用哪个包，或为什么没有。设置可能是*无*；包可能有问题（会列出文件和行号）；或者故事开始时它的世界没有界面包，所以故事里没有（若世界现在有了，用**从世界更新**）。只有在页面加载时有包声明了标签页，才会出现**界面**标签页：添加第一个之后请刷新页面。

**包的页面空白或没有样式：**包的页面只能用相对地址加载包内的文件，不能加载互联网上的任何内容。检查 `pack.json` 和页面中的文件名与路径（只能用字母、数字、`-`、`_` 和 `.`），以及文件类型是否被允许。页面不能发出网络请求，所以获取数据的脚本会在框架内失败。

**包里的按钮没反应：**让页面发言或填写输入框的调用需要在包的 `actions` 中列出 `say`、`fill` 或 `choose`；被拒绝的调用会带着原因拒绝其 Promise。文字为 1 到 2000 个字符，`say` 每回合一次，每秒超过 20 个请求会被拒绝。

**侧栏里没有界面包页面的入口：**打开右侧栏的引导页（它的 **+** 按钮，或收起后再展开）。只有界面包带有 `sidebar` 页面且正被使用的故事才会出现该入口；请查看**对话设置 → 界面包**。如果这个 DSH 配置里没有右侧栏，就无法显示该页面。

**背景被遮住或缺失：**DSH 在输入框上方绘制了一层渐隐，会遮住背景的下部；故事较短时能看到的更少。如果完全没有，浏览器控制台会说明页面没有放背景的位置，DSH 升级改变了聊天结构时可能出现这种情况。包的其余部分不受影响。

**世界的包改了，但我的故事没变：**故事在开始时复制世界的界面包。打开它的**对话设置**，使用**从世界更新**。被替换的副本保存在故事的 `.trash` 文件夹中。

**助手无法写入某个文件：**在创作对话中，文件工具只能触及 `<世界>/ui/<包>/` 中的文本文件（html、css、js、json、txt、svg，每次调用最多 200 KB）。其他一律拒绝，也无法请求更宽的权限。图片和字体请手动添加。

**每处改动都要批准两次：**会在每次 `write` 前询问的权限插件会先询问，而本插件也会询问。请放宽它对世界 `ui` 文件的规则，或接受两次提示。
