---
title: 术语表
---

**世界**：用于创建会话的可移植定义和初始状态。

**会话**：独立演化并拥有 SQLite 数据库的一个故事。

**GM**：协调角色轮次、解析结果并叙述的主智能体。

**角色智能体**：从单一角色有限视角做一次决策的智能体。

**轮次**：一组角色行动及 GM 解析；一个玩家回合可有多轮。

**事件**：客观、不可变的发生记录。

**感知**：某角色对事件可能不完整或错误的体验。

**信念**：跨越单个事件形成的持久认识。

**关系**：一个角色或阵营看待另一个对象的单向资料。

**实体知识**：表示角色能识别地点、物品、出口或设定条目的显式边。

**视觉身份**：用于保持生成图片一致性的稳定可见事实。

**记录员**：把已解析轮次转换成持久结构化记录的后台智能体。

**世界作者**：在游玩中或需要批准的创作对话中补充世界元素的智能体。

**界面包**：世界、故事或你的角色扮演目录中的一个纯文件文件夹，用来改变故事的样式，并添加自己的小页面。

**页面（surface）**：界面包的一个页面，显示在固定位置的沙盒框架中：状态条（`hud`）、`dock`、`opening` 卡片、`backdrop` 或 `tab`。

**皮肤**：界面包中改变故事自身文字样式的样式表，只限于故事用 `data-rp` 标明的元素。

**桥接（`rp`）**：页面调用的一组固定的小接口，用来读取玩家视图、以玩家身份发送文字、保存笔记和申请高度。

**玩家视图**：告知界面包的故事内容：只有玩家角色可能知道的部分。
