## 核心插件配置

这些值为整个 DSH 配置档案设置插件。会话设置则只属于一个故事。

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `rootPath` | `~/dsh-roleplay` | 存放世界、玩家角色、会话和媒体的文件夹 |
| `sessionStorePath` | `~/.dsh/sessions` | 保存角色扮演会话所关联对话的 DSH 会话目录 |
| `authoringTools` | 无 | 各创作助手可以使用的其他插件工具。分组为 `worldAuthoring`、`presetAuthoring`、`lorebookAuthoring` 和 `worldAuthor`。未列出的工具不可用；会话医生永远不会收到这些工具 |
| `catalogues` | 无 | 可浏览的世界目录。每项包含 `name`、API `baseUrl` 和可选的 `apiKeyRef`，指向 DSH 凭据存储（密钥本身保存在那里，不写入配置；旧版写下的 `apiKey` 文本不再被读取） |
| `sync.remote` | 空 | rclone 远端与文件夹，例如 `mydrive:dsh-roleplay`；留空则关闭同步 |
| `sync.rclone` | 空 | rclone 可执行文件；留空则从 `PATH` 查找 `rclone` |
| `sync.configFile` | 空 | rclone 配置文件的绝对路径，必须位于 `rootPath` 之外 |
| `sync.passwordRef` | 空 | 加密 rclone 配置所用的 DSH 凭据引用；留空使用 `ROLEPLAY_SYNC_RCLONE_CONFIG_PASS` |
| `sync.intervalMinutes` | `0` | 自动同步间隔；0 表示只允许手动同步 |
| `offload` | 无 | 不能同时加载的模型：`groups`（由 `main`、`embedding`、`reranker`、`decision`、`image`、`speech` 这些角色组成的列表）和 `models`（除 `main`（即对话自己的模型）外，各角色的 `route` 与 `model` 名称）。使用某个角色的模型之前，服务器会先卸载与它同组的其他角色的模型。留空则从不卸载 |
| `catalogueMaxBytes` | 256 MiB | 下载世界的大小上限，压缩包和解压结果分别检查 |
| `autonomyTickSeconds` | 30 | 查看已打开[“我不在时故事继续”](../playing/settings)的故事的间隔（秒，最短 5）；0 表示从不查看 |
| `catalogueTrashDays` | 30 | 目录更新替换的文件在 `.trash/worlds/` 中保留的天数；0 表示永久保留 |
| `importMaxUploadBytes` | 100 MiB | 角色卡上传大小上限 |
| `importConcurrency` | 4 | 可同时运行的导入与创作辅助请求数 |
| `importReasoning` | 空 | 导入与创作助手及创作对话的推理等级；留空依次使用 `childReasoning` 和对话设置 |
| `childReasoning` | 空 | 角色扮演辅助智能体的回退推理等级；留空跟随主持人 |
| `importModel` | 空 | 导入与创作助手使用的 `提供方/模型`；留空使用对话模型 |
| `importStructuredOutput` | `schema` | 导入和创作助手返回结构化结果的方式。`schema` 要求兼容端点用 `response_format` 约束 JSON 回复；LocalAI、vLLM 和 OpenAI 支持这种形式。如果端点拒绝 schema，此后该模型会改用工具调用。`tool` 让所有模型都使用工具调用 |
| `importMaxTokens` | 0 | 单次导入或创作辅助请求的输出令牌上限；0 表示模型上下文窗口的十分之一（至少 16000）；各任务可以用更小的限制 |
| `importVariablesPerRequest` | 25 | 一次导入请求要求声明的追踪数值数量；追踪更多的卡片会再次询问其余的 |
| `importTemperature` | 0.2 | 导入与创作助手的采样温度 |
| `importTimeoutMinutes` | 15 | 导入或创作助手未给出结果前最多运行的分钟数；0 表示不限时 |
| `importDecisions` | `llm` | `decision` 让已配置的决策服务先判断有把握的卡片片段；`llm` 把每个片段都交给语言模型 |
| `importConfidence` | 0.7 | 采用决策模型分类所需的把握程度 |
| `authoringApproval` | `ask` | `ask` 要求逐项批准世界创作对话的修改；`auto` 立即写入，并把被替换或删除的文件保存在世界的 `.trash` 文件夹中；预设和世界书助手同样遵循此项，但涉及游戏规则的提示词始终会询问 |

除需重启的 `sessionStorePath` 外，所有字段都可在**设置、角色扮演**中编辑，并立即生效。让多台设备使用同一远端前，请先阅读[多设备同步](../playing/sync)。

## 状态插件配置

状态包可以单独安装。以下选项配置它的数据库和面向模型的工具。

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `journalMode` | `delete` | SQLite 日志模式。`delete` 让会话保持为便于复制的单个文件；`wal` 允许写入期间继续读取 |
| `writeTools` | `false` | 注册可修改记录的模型工具。读取工具始终注册 |
| `diceTools` | `false` | 为所有角色扮演智能体注册骰子工具。完整套件改为按智能体类别授予 |

## 会话默认值

这些默认值会写入新故事的 `settings.json`。世界或预设可以建议不同的初始值，玩家也可以为该故事修改。

### 回合、记忆与上下文

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `maxRounds` / `maxCharacters` | 3 / 4 | 每条玩家消息的角色轮数，以及每轮激活的角色数 |
| `memory.flaky` | `true` | 启用不完美感知和随故事时间淡化 |
| `memory.recall` / `memory.lookupCalls` | 12 / 5 | 每次激活提供的记忆数，以及单次角色决策的查询上限 |
| `memory.lookup` / `memory.verify` | `true` / `true` | 允许角色查询记忆，并让记录员写入后复核 |
| `memory.backlogRounds` | 6 | 尚未记录的回合达到此数时强制记录员追上 |
| `memory.overRetrieve` / `memory.associate` | 4 / 2 | 最终筛选前的候选倍数，以及强匹配可带出的相关记忆数 |
| `memory.diversity` | 0.3 | 同时召回近似重复记忆的惩罚，范围 0 到 1 |
| `memory.foldedFade` | 0.5 | 感知被信念吸收后的保留倍率；1 表示不改变 |
| `context.limitTokens` / `context.limitRatio` | 0 / 0.6 | 明确的折叠上限，或用于计算上限的模型上下文比例 |
| `context.workingTokens` / `context.retainRatio` | 0 / 0.5 | 计算结果的可选上限，以及保留原文的比例 |
| `context.shortTermTokens` / `context.longTermTokens` | 1500 / 2500 | 短期和长期摘要的目标大小 |

### 世界活动与时间

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `authoring.enabled` | `true` | 允许主持人请世界作者补充缺失实体 |
| `authoring.perTurn` / `authoring.thingsPerTurn` | 2 / 4 | 每回合创作的角色和地点数，以及主持人可直接引入的普通物品数 |
| `authoring.consolidateAfter` | 3 | 待处理创作实体达到此数时整理 |
| `clock.mode` / `clock.timeZone` | `simulated` / 空 | 故事时间模式（`simulated` 或 `real`）及其 IANA 时区。开始会话时，现实时间留空则使用主机时区；模拟时间留空则依次使用世界时区和 UTC |
| `clock.roundSeconds` / `clock.maxSkipDays` | 30 / 30 | 模拟时间中一轮的默认秒数，以及一次时钟推进最多跨过的天数 |
| `background.concurrent` | `false` | 允许后台工作与下一回合重叠，而不是先完成再开始 |
| `autonomy.enabled` / `autonomy.messages` | `false` / `true` | 你不在时故事继续（仅真实时钟），以及角色可以给你发消息 |
| `autonomy.maxUnanswered` | 3 | 角色自行连续做的事达到这个数而你没有任何消息时，不再运行任何东西 |
| `autonomy.idleMinutes` / `autonomy.messageGapMinutes` | 15 / 180 | 你至少离开多少分钟后角色才会行动，以及同一角色两条消息之间的最短间隔（分钟） |
| `autonomy.awayHours` | 12 | 离开这么多小时之后，在你发言之前不再发生任何事 |
| `autonomy.chance` / `autonomy.decay` | 0.05 / 0.5 | 空闲时间过去之后每次查看时有人写消息的概率，以及每条没有回复的消息使它乘以的系数 |
| `autonomy.transitionChance` | 0.4 | 刚换了日程的角色在那次查看时写消息的概率 |
| `schedule.enabled` | `true` | 角色是否按各自的日程生活（日程和睡眠） |
| `decisions.errands` | `on` | 每回合之后，决策模型查看被点到的清醒角色，判断是否有人在等玩家（被派去办事、被告知留下或守望）；这样的角色会一直脱离日程，直到你和它再次相遇。仅由决策服务执行：`off` 或 `on`；没有服务时本环节不保持任何角色 |
| `decisions.messages` | `off` | 由决策模型判断被概率选中的角色是否有理由写消息；没有决策模型时只由概率决定 |
| `offstage.perTurn` / `offstage.perCharacter` | 2 / 1 | 每回合处理的离场角色数，以及每个角色的行动上限 |
| `offstage.joint` / `offstage.summary` | `true` / `true` | 一起处理重叠情境，并生成“与此同时”摘要 |
| `factions.perTurn` / `factions.everyDays` | 1 / 3 | 每回合推进的派系数，以及默认故事时间间隔 |
| `triggers.enabled` / `triggers.maxFires` | `true` / 3 | 是否运行触发器，以及每回合最多触发数 |
| `triggers.beatTurns` / `triggers.cueTurns` | 3 / 2 | 主持人节拍和角色提示等待采用的回合数 |
| `triggers.judgedPerTurn` | 2 | 每回合最多由模型判断的触发条件数 |

### 反思与决策检查

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `reflection.auto` / `reflection.everyTurns` | `true` / 20 | 自动反思及其回合间隔；0 关闭定时反思 |
| `reflection.onSceneChange` / `reflection.sceneDays` | `true` / 1 | 地点变化或经过这些故事天后也反思；0 关闭时间条件 |
| `reflection.minTurns` / `reflection.perRun` | 5 / 3 | 两次反思的最少间隔，以及一次自动处理的角色数 |
| `reflection.minNew` | 4 | 自动反思所需的新感知数；手动反思只需一条 |
| `decisions.triggers` / `decisions.reflection` | `hybrid` / `llm` | 用 `llm`、`decision`、`hybrid` 或 `shadow` 判断触发条件和信念证据。`hybrid` 接受决策模型有把握的答案，其余交给语言模型。没有配置决策模型时，会直接使用语言模型，不显示提示 |
| `decisions.agency` / `decisions.refusal` | `off` / `off` | 可选的输出检查，除上述四种模式外也可关闭 |
| `decisions.repeats` | `off` | 旁白在最近 `decisions.repeatTurns` 个回合（6，取值 1 到 30）里已经讲过的句子（至少 `decisions.repeatChars` 个字符，12，取值 6 到 60）。模式同上，另加 `strict`：不用任何模型，把每个重复都退回 |
| `decisions.reuse` | `off` | 回合结束后自动生成场景图之前，先让决策模型判断每张相近的已存图片的描述是否表现了这一刻，并展示第一张符合的图片，不再生成新图。仅由决策服务执行：`off` 或 `on` |
| `decisions.variables` | `llm` | 每个回合之后检查所有被追踪的数值（世界变量，以及在场角色的角色变量）：对每个数值提一个问题，即刚才发生的事是否改变了它，交给语言模型、决策模型或两者；之后由语言模型给出改变了的数值的新值。请填写每个数值的 **何时、如何变化** 字段。模式与上述四种相同，另可关闭 |
| `decisions.rules` / `decisions.secrets` | `off` / `off` | 仅由决策服务执行的规则复查和隐藏背景检查 |
| `decisions.reuseThreshold` | 0.85 | 决策答案从此概率起算作“已存图片表现了这一刻”（0.1 到 0.95） |
| `decisions.gateThreshold` | 0.5 | 决策答案从此概率起算作问题；低于它 0.15 以内视为不确定 |
| `decisions.confidence` | 0.7 | 决策答案被采用而非交给语言模型所需的把握程度 |

各模式及回退规则见[可选能力集成](../specifications/capability-integration)。

### 模型、提示词与采样

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `models.characters`、`models.records`、`models.suggestions`、`models.authoring` | 空 | 对应助手使用的 `提供方/模型`；留空使用对话模型 |
| `models.background` | 空 | 背景角色模型；留空回退到 `models.characters` |
| `sampling.master` / `sampling.characters` | 0.7 / 0.8 | 主持人和角色的温度 |
| `sampling.suggestions` / `sampling.authoring` / `sampling.records` | 0.2 / 0.4 / 0.1 | 建议、创作和记录的温度 |
| `sampling.topP` / `sampling.topK` / `sampling.minP` | 1 / 0 / 0 | 其他采样参数；默认值不发送 |
| `sampling.frequencyPenalty` / `sampling.presencePenalty` / `sampling.repetitionPenalty` | 0 / 0 / 1 | 惩罚参数；默认值不发送 |
| `sampling.tools` | `required` | 必须提交结果的辅助请求所用的工具选择模式 |
| `sampling.masterMaxTokens` | 12000 | 主持人单次请求的最大输出令牌数，含推理 |
| `sampling.maxTokens` / `sampling.shortMaxTokens` | 8000 / 2000 | 一般和短辅助请求的输出上限 |
| `sampling.headroom` | 2 | 在上限内按预计回答长度扩大的倍数 |
| `prompts.language` | `en` | 内置提示词语言：`en` 或 `zh` |
| `reasoning.children` | 空 | 辅助智能体的推理等级；留空使用插件级回退值 |

### 界面、规则与媒体

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `interface.pack` | 空 | 留空使用世界中的第一个界面包，`none` 表示不用，填写名称则选中该包 |
| `rewind.keepSnapshots` | 30 | 为回退故事保留的近期状态快照数 |
| `rules.own` | 空 | 玩家为本故事补充的规则 |
| `preview.enabled` | `true` | 完整回合仍在生成时先显示场景预览 |
| `suggestions.count` | 3 | 回合结束后显示的行动建议数 |
| `dice.visibility` | `card` | `card` 在折叠卡片中显示骰子，`hidden` 不显示 |
| `tools` | 未选择 | 按智能体类别（`gameMaster`、`characters`、`records`）和名称设置的可选工具；未知名称会保留并忽略 |
| `images.mode` | `manual` | `off`、`manual` 或 `every-turn` |
| `images.references` | `prefer-reference` | `prefer-reference`、`require-reference` 或 `text-only` |
| `images.reuse` / `images.highRes` | `true` / `false` | 复用已有图片，以及可选的第二次大图渲染 |
| `images.interpret` | `true` | 为故事描述上传的图片 |
| `images.interpreterModel` / `images.captioner` | 空 / 空 | 理解上传图片和为生成图片写说明的模型；留空使用对话模型 |
| `diagnostics.keepRuns` | `false` | 在会话文件夹中保留最近 60 次辅助运行追踪，其中包含角色私密上下文 |

界面会显示当前数值边界。未知字段会被拒绝。提供方专属的嵌入请求参数保存在 `embedding.options`。
