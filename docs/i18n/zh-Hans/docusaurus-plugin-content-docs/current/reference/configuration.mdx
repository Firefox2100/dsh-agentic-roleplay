## 插件配置

| 字段 | 默认值 |
| --- | --- |
| `rootPath` | `~/dsh-roleplay` |
| `sessionStorePath` | `~/.dsh/sessions` |
| `authoringTools` | 无 | 其他插件为所有人注册的工具（网络搜索、MCP 服务器）中，每个创作助手可以使用的：`worldAuthoring`、`presetAuthoring`、`lorebookAuthoring` 和 `worldAuthor`（游戏中补充内容的辅助智能体），各自是设为 `true` 的工具名列表。助手没有未列出的工具；会话医生永远没有任何工具。在“设置 → 角色扮演 → 创作助手的工具”中编辑 |
| `catalogues` | 无（列表项含 `name`、`baseUrl` 即 API 根地址、可选的 `apiKeyRef`，即 DSH 凭据存储中保存 API 密钥的凭据名称，默认由名称生成；0.3 以 `apiKey` 文本保存的密钥在存储中没有密钥时仍会被读取，保存设置时被删除；在“设置 → 角色扮演 → 目录”中编辑） |
| `catalogueMaxBytes` | 256 MiB（下载的世界压缩与解压后的大小上限） |
| `catalogueTrashDays` | 30（更新所替换的文件在 `.trash/worlds/` 中保留的天数，之后删除；0 表示永久保留） |
| `importMaxUploadBytes` | 100 MiB |
| `importConcurrency` | 4 |
| `importReasoning` | 空 |
| `childReasoning` | 空 |
| `importMaxTokens` | 16000 |
| `importTemperature` | 0.2 |

## 主要会话默认值

`maxRounds` 为 3，`maxCharacters` 为 4；记忆回忆 12 条、候选倍率 4、积压 6 轮，`memory.diversity` 默认为 `0.3`，以减少近似重复的回忆；`memory.foldedFade` 默认为 `0.5`，让已被信念归纳的感知按原保留时间的一半淡化，设为 `1` 则不改变；上下文限制默认取模型窗口 60%，折叠后保留 50%；世界扩展每回合最多 2 个角色或地点；模拟时钟每轮默认 30 秒；回退保留 30 个快照；`interface.pack` 默认为空（使用故事自带的第一个界面包，`none` 表示不用）；提供 3 条建议行动；图片为手工模式，优先参考图、启用复用和上传图片理解。

`models.characters`、`models.background`（背景层级角色，留空则同 `models.characters`）、`models.records`、`models.suggestions`、`models.authoring` 默认为空，即各类助手使用对话自己的模型；填写 `提供方/模型` 可为其单独指定。

`sampling.topP`、`sampling.topK`、`sampling.minP`、`sampling.frequencyPenalty`、`sampling.presencePenalty`、`sampling.repetitionPenalty`（默认 1、0、0、0、0、1）是温度之外、用于主持人和角色请求的控制；每一项的默认值表示交给模型服务器自己的选择，不会发送。世界或预设可以为某一个故事建议它们。

`sampling.maxTokens` 默认为 `8000`，`sampling.shortMaxTokens` 默认为 `2000`，分别作为一般辅助智能体及角色/建议作者单次请求的生成上限。对于已经声明回答大小的辅助智能体，实际预算按估算值乘以 `sampling.headroom`（默认 `2`）计算，但不会超过相应上限。

设置界面会给出当前数值边界。未知字段会被拒绝。提供方专属嵌入参数保存在 `embedding.options`。

`dice.visibility` 为 `card`（默认）时在叙述下方用折叠卡片显示掷出的骰子，为 `hidden` 时什么都不显示。`tools` 按智能体类别（`gameMaster`、`characters`、`records`）和工具名给出 `true` 或 `false`；不认识的名字会被保留并忽略。状态插件另有配置项 `diceTools`（默认 `false`），为所有角色扮演会话的智能体注册骰子工具。
