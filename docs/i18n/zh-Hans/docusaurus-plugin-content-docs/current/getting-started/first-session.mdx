---
title: 开始第一个会话
---

点击世界卡封面的播放按钮。开始窗口会要求选择：

- 会话名称；
- 可扮演角色；
- 世界提供多个开场时，要使用的开场；
- 模拟时钟模式下的故事开始时间；留空则使用世界自身设置，实时模式会从当前时间开始；
- 一个写作指令[预设](../authoring/presets)（有预设或世界提出建议时）；
- 可选的[世界书](../authoring/lorebooks)背景知识（世界建议的已勾选）；
- 要带入此会话的可复用化身；
- 可选的高级角色扮演设置。

启动时会验证完整角色列表，创建 UUID 会话目录和 SQLite 数据库，复制世界的定义与初始状态，并创建 DSH 对话。任一步骤失败都会清除未完成的会话。

第一条消息之前，输入框上方的卡片会列出世界检查发现的未完善之处（例如无人能到达的地点，或不在任何地点的角色）。它不会阻止开始，并在第一回合后消失。

世界的开场消息作为完整的第一回合直接保存，不调用模型。玩家的第一条消息才会启动正常 GM 循环。

第一次行动请自然描述，不需要重新提示整个系统。写下角色说的话、尝试的行动、观察的事物或等待的结果即可。角色扮演预设已经提供世界规则、当前场景和更新状态所需的工具。

例如：

- `我压低声音：“还有谁知道天文台已经打开？”`
- `仔细搜索书桌，特别留意最近被移动过的东西。`
- `我一言不发，观察亚瑟听到那个名字后的反应。`

最终回答前可能发生多轮角色决策。更长并不一定更好；有上限的轮次可以避免一条消息演变成失控的模拟。

游玩不会修改源世界。角色状态、关系、知识、物品、时钟、记忆、剧情进度和生成媒体都属于会话。

从**角色扮演 → 会话**打开已有故事。有关分支、回退和删除，参见[会话与时间线](../playing/sessions)。
