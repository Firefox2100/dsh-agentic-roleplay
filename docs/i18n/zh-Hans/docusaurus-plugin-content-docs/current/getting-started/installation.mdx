title: 安装
---

## 要求

- DeepSeek Harness 0.2.x；
- Node.js 22 或更高版本；
- 带网页界面的 DSH 配置档案；
- 至少一个能运行 GM 和子智能体的语言模型路由。

[rclone](https://rclone.org) 是可选依赖。只有需要[在多台设备间同步资料库](../playing/sync)时才需要安装；仅在本机游玩不会调用它。

建议使用专用 DSH 配置档案。套件会加入角色扮演预设、侧边栏界面、设置、会话页签、语音输入和配套插件；将它们放在专用配置档案中可以避免影响无关的 DSH 工作区。

```bash
dsh plugin --profile <profile> add @dsh-agentic-roleplay/all
```

套件会安装角色扮演核心和 `@dsh-agentic-roleplay/state`。重启该配置档案后，从 DSH 侧栏打开**角色扮演**。

## 首次运行清单

1. 在**设置 → 角色扮演**中设置存储根目录。
2. 配置至少一个语言模型路由。项目维护的提供方集成见 [AI 服务](./ai-services)。
3. 打开**角色扮演 → 世界卡**，添加示例世界或创建自己的世界。
4. 点击世界卡上的播放按钮，选择可扮演角色并开始会话。

套件不包含模型凭据，也不会下载模型。只有相应服务可用时，媒体和检索增强功能才会出现。

## 存储根目录

在**设置 → 角色扮演**中选择绝对路径作为数据根目录。默认值是 `~/dsh-roleplay`，支持开头的 `~`。世界、化身、会话数据库和媒体都位于其中；插件配置和凭据仍由 DSH 配置档案管理。

修改根目录后，只要新值有效，目录会立即切换。无效修改会被拒绝，并继续使用先前目录。

请将此目录视为你的角色扮演资料库。备份它即可保存创作的世界、可复用化身、会话数据库、生成媒体和会话设置。不要让两个同时运行的配置档案指向同一根目录。

## 更新

更新套件后应重启配置档案。升级 DSH 次版本前请查看项目说明，因为子智能体组合依赖少量与 DSH 版本相关的接口。

下一步请阅读 [AI 服务](./ai-services)。
