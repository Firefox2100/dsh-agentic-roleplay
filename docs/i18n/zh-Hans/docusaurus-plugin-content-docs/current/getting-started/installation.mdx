---

## 要求

- DeepSeek Harness 0.2.x；
- Node.js 22 或更高版本；
- 带网页界面的 DSH 配置档案；
- 至少一个能运行 GM 和子智能体的语言模型路由。

[rclone](https://rclone.org) 是可选依赖。只有需要[在多台设备间同步资料库](../playing/sync)时才需要安装；仅在本机游玩不会调用它。

建议使用专用 DSH 配置档案。套件会加入角色扮演预设、侧边栏界面、设置和会话页签。放在专用配置档案中，可以避免影响无关的 DSH 工作区。

```bash
dsh plugin --profile <profile> add @dsh-agentic-roleplay/all
```

套件会安装角色扮演核心和 `@dsh-agentic-roleplay/state`。重启该配置档案后，从 DSH 侧栏打开**角色扮演**。

套件只是方便，并非必需。`@dsh-agentic-roleplay/core` 带有同一层配置，包括状态插件、角色扮演与助手预设、三个创作助手和会话医生，因此这样安装同样可用：

```bash
dsh plugin --profile <profile> add @dsh-agentic-roleplay/core
```

单独安装 `@dsh-agentic-roleplay/state` 只会加入故事数据库及其工具，供基于它的其他插件使用。

麦克风输入是可选功能。需要时，请从 DSH 自己的插件列表安装并启用 **Voice Input**。角色扮演套件不再安装 DSH 的语音包，因此这些包可以与 DSH 运行时保持同一版本。SenseVoice 提供方、API 语音识别提供方可以任选，也可以同时使用。

如果只想使用 API 识别，可以隐藏 SenseVoice。Voice Input 套件会加入本地 SenseVoice 提供方并把它设为默认，不过它只在你要求准备时才下载模型。把下面的内容加入配置档案的 `cordis.patch.yml`，其中 `openai` 或 `localai` 是你在 AI 提供方设置里为语音转文字选择的提供方：

```yaml
- id: speech-to-text
  name: '@deepseek-ai/dsh-experimental-speech-to-text'
  config:
    defaultProvider: openai
- id: speech-to-text-sensevoice
  disabled: true
```

禁用 SenseVoice 后，只会提供 API 识别，也没有需要准备的模型。识别器把每段录音整体发送给已配置的服务，所以没有实时管线的 Whisper 模型也可以使用。

这些层只应选中一个：`@dsh-agentic-roleplay/all` 或 `@dsh-agentic-roleplay/core`。它们加入相同的插件行，而且核心层已包含状态插件，所以在任何一层旁边再选 `@dsh-agentic-roleplay/state` 层也是多余的。同时选中两层时，配置档案里同一行会出现两次，DSH 会拒绝保存**设置 → 角色扮演**（提示“此部署未接受这些值”）。若使用插件管理器，请取消多余的层（包保持安装），然后重启。发现这种情况时，角色扮演设置页会显示警告，日志里也会记录错误。

## 首次运行清单

1. 在**设置 → 角色扮演**中设置存储根目录。
2. 配置至少一个语言模型路由。项目维护的提供方集成见 [AI 服务](./ai-services)。
3. 打开**角色扮演 → 世界卡**，添加示例世界或创建自己的世界。
4. 点击世界卡上的播放按钮，选择可扮演角色并开始会话。

套件不包含模型凭据，也不会下载模型。只有相应服务可用时，媒体和检索增强功能才会出现。

## 存储根目录

在**设置 → 角色扮演**中选择绝对路径作为数据根目录。默认值是 `~/dsh-roleplay`，支持开头的 `~`。世界、化身、会话数据库和媒体都位于其中；插件配置和凭据仍由 DSH 配置档案管理。

修改根目录后，只要新值有效，目录会立即切换。无效修改会被拒绝，并继续使用先前目录。

请将此目录视为你的角色扮演资料库。备份它即可保存创作的世界、可复用化身、会话数据库、生成媒体和会话设置。不要让两个同时运行的配置档案指向同一根目录。

## 更新

更新套件（若你安装的是核心包，则更新核心包）后应重启配置档案。无需先卸载任何东西：各行相同，已装 `all` 套件的配置档案照常工作；只安装过核心包并自己写了预设行的配置档案会保留自己的行，因为配置档案自己补丁中的行会取代同一 id 的内置行。升级 DSH 次版本前请查看项目说明，因为子智能体组合依赖少量与 DSH 版本相关的接口。

### 从 0.9.0 升级

0.9.0 随套件安装了 DSH Voice Input 的组件。0.9.1 将它们移出套件，使其版本可以独立跟随 DSH。先停止该配置档案，再在现有安装上安装 0.9.1：

```bash
dsh plugin --profile <profile> add @dsh-agentic-roleplay/all@0.9.1
```

重新启动配置档案。若需要麦克风输入，请打开插件管理器，启用 DSH 的 **Voice Input** 插件。不要为旧语音包添加版本豁免。角色扮演根目录与插件安装位置分开，此更新不会删除世界或会话。如果你手工编辑过配置档案的补丁文件，请先备份配置。

下一步请阅读 [AI 服务](./ai-services)。
