---
title: 创建第一个世界
---

全新安装时世界卡页面是空的，并提供一个示例世界《黑水天文台》（1912 年山镇悬疑，含四名角色及地点、物品、变量和触发器）。点击**添加这个示例世界**会把它复制到你的世界中成为你自己的世界，可游玩、编辑或拆解；它不会被覆盖，你拥有之后也不再提供。

示例世界是开始第一次会话最快的方式，也是可以实际运行的参考。打开编辑器即可查看角色目标、私有知识、关系、地图连接和确定性触发器如何配合。

要创建自己的世界，打开**角色扮演 → 世界卡**并选择**创建世界**，填写存储用的文件夹名和展示给用户的世界名称。插件会创建带稳定 UUID 的 `world.json` 并打开世界编辑器。

最小可玩世界需要：

1. 添加一个角色。
2. 将其角色类型设为**可扮演**。
3. 填写名称、简介和初始状态。
4. 如果空间玩法很重要，至少添加一个地点。
5. 如果会话需要作者预写的开场旁白，在 `world.json` 中填写开场消息。

这些内容已经足够开始游玩。设定资料、阵营、剧情、日程、变量、触发器、声音和图片都可以逐步添加。对于第一次测试，少量互相冲突的角色动机通常比庞大但缺少行动动力的百科设定更有效。

开始前，可以从三个角度检查：

- **玩家可以尝试什么？** 让开场场景中存在具体可观察、可追求或可质疑的事物。
- **每个角色想要什么？** 目标和约束可以在不编写固定对白的情况下产生行动。
- **哪些内容是私密的？** 将秘密放入相应角色知识、内在状态或受限设定资料中，而不是公开描述。

通常应使用编辑器。也可以直接修改文件，但之后需要刷新世界列表。验证错误会标出文档路径，并阻止无效世界开始会话。

**创作世界**按钮会在相同工作区打开专用创作对话，其写入操作都需要用户批准。参见[创作助手](../authoring/assistant)。
