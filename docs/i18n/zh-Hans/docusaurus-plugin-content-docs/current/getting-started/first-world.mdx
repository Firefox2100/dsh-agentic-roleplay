---
title: 创建第一个世界
---

全新安装时世界卡页面是空的，并提供一个示例世界《黑水天文台》（1912 年山镇悬疑，含四名角色及地点、物品、变量和触发器）。点击**添加这个示例世界**会把它复制到你的世界中成为你自己的世界，可游玩、编辑或拆解；它不会被覆盖，你拥有之后也不再提供。

要创建自己的世界，打开**角色扮演 → 世界卡**并选择**创建世界**，填写存储用的文件夹名和展示给用户的世界名称。插件会创建带稳定 UUID 的 `world.json` 并打开世界编辑器。

最小可玩世界需要至少一个角色，并将其设为**可扮演**。为角色填写名称、简介和初始状态；需要空间玩法时再添加地点。可在 `world.json` 中编写无需模型调用的开场消息。

通常应使用编辑器。也可以直接修改文件，但之后需要刷新世界列表。验证错误会标出文档路径，并阻止无效世界开始会话。

**创作世界**按钮会在相同工作区打开专用创作对话，其写入操作都需要用户批准。
