---
title: 配置 AI 服务
---

角色扮演始终需要 DSH 语言模型路由。其他能力会在运行时按是否存在来启用。

| 能力 | 用途 | 未配置时 |
| --- | --- | --- |
| 语言模型 | GM、角色、记录员、创作与摘要 | 无法进行会话 |
| 嵌入 | 语义记忆、设定和图片检索 | 仍使用关键词和显式线索 |
| 重排序 | 精排候选记忆 | 直接采用检索分数 |
| 图片生成 | 肖像和场景插图 | 图片操作明确报告未配置 |
| TTS | 旁白和角色语音 | 不提供播放或明确失败 |
| STT | 录音与实时语音输入 | 正常使用文字输入 |

通过 [DSH AI Providers](https://firefox2100.github.io/dsh-ai-providers/zh-Hans/docs/intro) 安装和配置服务。在**设置 → AI Providers**中选择各项服务，并为 DSH 配置语言模型路由。

本地推理应配置并发限制，使共用 GPU 的前台请求优先于向量索引等后台工作。图片理解需要被提供方声明为支持图片输入的模型；自动上下文限制需要正确的模型上下文长度元数据。
