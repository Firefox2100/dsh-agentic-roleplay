## 可复用化身

玩家化身位于角色扮演根目录，而不属于某个世界。在**化身**页创建和编辑。可以把化身复制进世界成为可扮演角色，也可以只在开始会话时带入，不改变世界。

复制品彼此独立。之后修改原化身不会重写世界或已有会话。

可复用化身适合保存玩家角色的稳定部分：姓名、代词、外观、声音、性格和可移植背景。世界专属关系、当地知识、物品与起始位置应放在世界或会话副本中，避免角色在不同设定之间携带不可能拥有的知识。

### 复制到世界还是只加入会话？

- 当化身属于世界设计好的固定角色，并应出现在每个未来会话中时，复制到**世界**。
- 当某位玩家只想把它带入本次游玩，而不改变世界时，添加到**新会话**。
- 设定需要本地变体时，编辑复制出来的角色；可复用来源保持不变。

## 角色卡

导入器接受支持的角色卡，提取文字与图片，再由导入智能体映射到原生角色格式。可以安全获取并验证的图片会进入世界图库。

导入器还会带上角色对世界中地点、物品和地点之间路线的了解，给卡片在他人关系中提到的角色补上一条普通的熟人关系，并让每个角色知道与自己有关的设定。要让世界采用 SillyTavern 提示预设的叙述风格，请使用世界编辑页顶部的**导入叙述预设**：编辑助手会把预设中的指令转成世界的叙述与角色风格提示词，并在替换前询问你。预设中的游戏规则、格式和脚本不会被带入。

导入后必须检查数据。角色卡很少像原生模型那样明确区分公开事实、私密状态、稳定外观、起始行动和长期目标。

重点检查：

- 哪些事实可以公开，哪些应放入 `inner_state` 或显式知识；
- 哪些文字是聊天机器人回复指令，而不是世界中的人物特征；
- 示例对话是否应转换成说话风格，而不是当前对白；
- 哪些外观足够稳定，可以进入视觉身份；
- 角色目标和起始活动是否能让它在开场时有事可做；
- 导入姓名或 ID 是否与现有角色冲突。

导入结果是一份草稿，不是持续同步层。转换完成后，原生角色文件与复制的图片成为权威内容；修改原始角色卡不会自动更新它们。

### 角色卡的新版本

由角色卡导入的世界，可以按这张卡的新版本更新到最新，而不必重新跑一遍导入。有两种入口：

- **照常导入这张卡**（世界页面的**导入角色卡**按钮，或来自[目录](../playing/catalogue)的卡）。如果你已有同名世界，而且那个世界本身就是由角色卡导入的，查看页面会在**作为新世界导入**旁边提供**用这张卡更新“名称”**。卡改过名字时，可以更新任何由角色卡导入的世界：选择**更新另一个世界**，再从列表里挑。
- **从世界本身。**打开一个由角色卡导入的世界，它的标题栏有**用角色卡更新**。选择卡文件（PNG 或 JSON），查看页面会打开，并已选中这个世界。想用磁盘上的卡更新世界、又不想经过目录时，用这种方式。

更新不会重新跑一遍导入。在任何改动之前，插件会先保存世界当前的样子。新卡放在世界的 `.import/update` 文件夹里，世界的创作对话随之打开，并被告知让世界与新卡保持一致：

1. `card_diff` 显示两张卡之间的变化，由插件算出：每个有变化的片段（字段、问候语或世界书条目）里不同的句子，以及新增或被删去的片段。每个变化的片段会列出导入由它生成的角色、地点和物品；被删去的片段还会列出只由它生成的那些。它也会列出卡对世界本身做了哪些改动。
2. 助手用 `card_read` 读取需要的片段（`version` 为 `current` 是旧卡，`new` 是新卡），然后用普通的编辑工具只改新卡改动的部分。角色、地点和物品像其他改动一样编辑；世界对自身的描述（简介、标签、开场和其他开场）用 `edit_world_info` 修改。每项改动和其他改动一样要经过[批准](./assistant#批准)，并且会显示改了什么。只由已被删去的片段生成的内容会被移除（文件夹放进世界的 `.trash`），除非导入之后你修改过它。
3. `card_update_finish` 把新卡变成世界的来源卡（旧卡保存在 `.import/previous`），把世界当前的文件记作区分之后修改的新起点；如果世界的头像仍是旧卡自带的图片而新卡换了图片，也会一并替换，并获取世界里还没有的图片地址。上次因可能已经消失的原因（超时、服务器错误）失败的地址也会再试；图库里已有的图片按图片本身识别，而不是按文件，所以镜像地址不会多出一份副本。新卡不再列出的地址所对应的图片仍留在图库里，助手会告诉你是哪些。

只有变化的片段才有成本，所以角色卡的小更新只需要一次导入的一小部分。默认选项取决于导入之后你是否修改过世界（导入的检查结束时，插件会记下世界文件的指纹；图片不算）：

- **没有修改过：**世界与卡同名时，默认选中**更新**。
- **修改过：**默认选中**作为新世界导入**。你仍可以选择更新，这时助手会看到你修改过的文件，并被告知保留你的修改。
- **导入时尚未记录指纹：**插件无法判断，同样默认选中新世界。选择更新时流程相同，助手会先查看世界再动手。

更新会保留世界的名称；已经由这个世界开始的会话保留自己的副本，更新不会改变它们，要玩更新后的世界请开始新会话。

如果结果不是你想要的，世界标题栏的**撤销卡片更新**会让世界回到更新之前的样子，并恢复它所依据的角色卡。那一刻世界里的内容会移到它的 `.trash` 文件夹，更新之后你做的修改仍然找得回来。图片不在撤销范围内。

导入上限、并发、推理强度、token 预算和温度在核心插件中配置。网络图片只有在地址和响应类型都通过验证后才会获取。

若角色卡过大或含糊，请把来源缩减为真正定义角色的事实，再通过编辑器补充设定专属内容。动机清晰的精炼角色，比充满重复示例和指令的长卡更适合运行时使用。
