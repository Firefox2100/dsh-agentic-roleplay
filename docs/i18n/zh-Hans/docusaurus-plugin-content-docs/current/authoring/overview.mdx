---
title: 世界创作概览
---

世界是可复用的起点，而不是存档。它定义身份、初始状态、设定知识和潜在剧情。每个会话复制这些数据后独立演化。

开始游玩前不必设计完所有系统。先建立一个局面：玩家可以扮演的人、一个承受压力的地点，以及两三名目标互相冲突的角色。经过实际测试后，再用编辑器和创作助手扩展世界。

适合智能体玩法的世界应提供有动机与限制的角色、有意义相连的地点、公开事实与私密状态的区分、不会强迫结果的剧情机会，以及必须确定执行的触发器。应为玩家选择留下空间，而不是预写对话和结局。

稳定事实放在定义中；初始位置、行动、情绪、意图和变量值放在初始状态中。可以使用[世界编辑器](./editor)、需要批准的[创作助手](./assistant)，或依据[文件格式参考](../world-format/overview)直接编辑。

## 实用的创作顺序

1. 定义世界前提、基调和规则。
2. 创建至少一名可扮演角色，以及开场时身边的人。
3. 连接开场地点，并放置初始角色和重要物品。
4. 为角色填写目标、有方向的关系，以及他们在开场时真正知道的内容。
5. 写一个能呈现张力、但不替玩家决定反应的开场。
6. 在需要产生智能体无法可靠推断的后果时，再添加设定资料、剧情、日程、阵营、变量和触发器。

扩大规模前先进行一次短会话。如果角色缺少方向，应先加强意图或局面，而不是继续添加背景资料。如果角色知道得太多，请检查明确知识和公开描述。如果 GM 过于急切地推动一条剧情，请让剧情节点保持可选并增加冷却，而不是删除所有结构。

世界还可以携带[界面包](./interface-packs)：主题、皮肤和小页面，用来改变它的故事的外观。
