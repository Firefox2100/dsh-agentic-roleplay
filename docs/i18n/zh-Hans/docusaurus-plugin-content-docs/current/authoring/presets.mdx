---
title: 预设
---

**预设**是你保存在资料库里、可以放进任何故事的一组写作指令：叙述者是谁、叙述读起来如何、角色怎样说话和行动。它以行文方面的文字为主；游戏规则以及只属于某个世界的内容都留在世界里，唯一的例外见[规则类提示词](#规则类提示词)。

:::note
这不是 DSH 的*智能体预设*（它决定一个对话以什么智能体运行）。这里的预设只是叙述提示词。
:::

每种语言下，预设最多带有三个提示词：

| 提示词 | 决定什么 |
| --- | --- |
| `roleplay/persona` | 叙述者是谁 |
| `roleplay/style` | 叙述怎么写 |
| `roleplay/character-style` | 角色怎样说话和行事 |

预设还可以建议叙述者和角色的创作温度。

### 规则类提示词

预设也可以带有故事的其他提示词，也就是属于游戏规则的那些：游戏主持人如何主持一个回合、角色可以知道和做什么。它们涉及程序读取的工具和字段，改错可能会破坏故事的运行。除非有人放进去，否则它们不属于预设；凡是带有它们的预设，在显示的每个地方都会带警告：预设卡片上、编辑器里，以及助手请求的批准中。助手修改规则类提示词时，会保留原有文字并在其后追加，而不是替换。编辑器可以修改预设已带有的规则类提示词的文字；添加则要靠助手，或通过[导入含有指令的世界书](lorebooks#给-ai-的指令)。

## 预设页

角色扮演面板里的**预设**页列出你的资料库：每个预设的标题、描述、带有提示词的语言，以及妨碍它被使用的问题。

- **新建预设**以内置的各语言叙述提示词为起点。起一个名称（字母、数字、`-` 和 `_`；故事和世界通过这个名称引用它），然后改写提示词。
- **编辑**打开预设：标题、描述、建议的采样设置，以及它带有的每个提示词的文字。预设缺少的提示词或语言可以从提示词下方的列表中添加。规则类提示词从另一个列表添加，以内置文本为起点并显示警告，因为修改现成的规则类提示词比从零写起更安全。保存时会像故事开始时那样检查提示词，因此原文中的 `${占位符}` 必须保留。
- **用助手编辑**为预设打开一个创作聊天，与世界的创作聊天类似。助手会读取预设，提出对提示词、标题、描述和温度的修改，并在每次写入前征求你的同意；你拒绝则不会有任何改动。适合较大的改写，或让它代写提示词。
- **导入酒馆预设**接受 SillyTavern 导出的 `.json` 文件，并先显示其中有什么：每个提示词，按预设发送的顺序排列，预设中已开启的会被预先勾选。勾选你想要的（一份预设常带有几个可替换的版本，比如每种文风一条提示词，而只开启其中一条）：只有勾选的提示词会交给转换，其余的会被当作文件里根本没有，它们设置的内容也一样。预设自带的采样设置（温度、Top P 等）也会列出，除非取消勾选，否则会保留。对话框还会说明文件中有哪些内容不会被带入，比如改写回复的正则表达式和写出该预设的工具的辅助脚本。随后助手只保留关于叙述方式的部分（叙述者、文风、角色说话方式），写进一个新预设；游戏规则、格式和脚本不会被带入。只读取预设中已开启的提示词，并按它发送的顺序；其中的变量宏（`setvar`、`getvar`）会先被执行，使某个提示词里设置的值出现在另一个提示词引用它的地方；以模型自己的回合写成的提示词（为某个特定模型准备的预填充）会被跳过。围绕某个模型的思考模板或破限语句构建的预设，导入后只留下其叙述文风。
  勾选**不使用助手**可跳过转换：不会运行任何模型，勾选的提示词按文件发送的顺序、并在播放完文件自带的变量之后，立即原文成为新预设的叙述风格。叙述与角色之间不会拆分，文件里的规则也不会梳理，所以请在预设的编辑器里检查结果。想要预设完全保持原样，或者没有多余的模型可用时，就用它。
- **删除**会把预设移到回收文件夹。已经在使用它的故事保留各自的副本。

[目录](../playing/catalogue)的**预设**标签页列出他人发布的酒馆预设。**导入为预设**会下载它，像文件导入那样先询问要带入什么，再用它生成资料库中的一个新预设。再次导入会生成另一个预设，因为助手每次的转换结果并不相同。

## 采样设置

预设和世界都可以建议故事的模型如何被请求：`preset.json` 或 `world.json` 中的 `sampling`，包括叙述者的 `master` 与角色的 `characters` 温度（0 到 2），以及 `topP`、`topK`、`minP`、`frequencyPenalty`、`presencePenalty`、`repetitionPenalty`，后者作用于叙述者和角色，不会用于需要精确的辅助者。不想建议的就留空；只是重复模型服务器默认值的取值不会被发送。

```json
{ "sampling": { "master": 0.9, "characters": 0.9, "topP": 0.95 } }
```

这些值在故事开始时被复制进**那一个故事**的设置，只有那个故事这样向模型提出请求。顺序是：世界的值，其次是预设的（世界建议的或开始时选择的），最后是你在开始对话框或之后在聊天设置中的选择。不会写回资料库或世界，正在进行的故事在切换预设时也保留自己的设置。它们可在预设的**概览**和世界编辑器的**概览**中编辑。导入酒馆预设也会以同样方式带入它的采样设置：它唯一的温度会同时成为叙述者和角色的温度；温度过高会让某些模型用文字回答而不调用工具，故事卡住时请调低。

世界自带的提示词也可以变成预设：在世界编辑器的**提示词**页，**存为预设**会把世界带有的叙述类提示词复制成一个新预设。

## 使用预设

故事在开始时会把预设**复制**进来，之后对资料库的修改不会改变进行中的故事。

- **在世界中：**编辑器“概览”页的**建议的预设**字段，或创建世界的对话框，指定这个世界的新故事默认使用的预设。世界自带的提示词仍然优先于它。
- **开始故事时：**开始对话框提供资料库中的预设、“不使用预设”和世界的建议。在这里做出的选择优先于世界自带的提示词。
- **在进行中的故事里：**对话设置的**预设**区域显示故事是否仍与资料库一致（*一致*、资料库中*已更改*、故事中*已编辑*、资料库中*已缺失*），并可以切换到另一个预设、重新应用资料库中的版本，或取消预设。被替换的副本保存在故事的 `.trash/prompts/`。

切换预设不会改变故事的温度，世界带有、但被先前预设替换掉的提示词也不会恢复。回合进行中会拒绝切换，因此提示词不会在回合中途改变。

预设也可以来自[世界书](lorebooks)的导入：酒馆世界书中给 AI 的指令会被单独保存，经你同意后变成一个新预设。

完整规则（文件写入的顺序、哪些算问题）见[提示词系统](../specifications/prompt-system#预设)规范。
