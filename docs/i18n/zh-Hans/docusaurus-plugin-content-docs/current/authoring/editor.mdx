---
title: 世界编辑器
---

同一编辑器会从世界列表、角色扮演会话和世界创作对话中打开。编辑世界影响未来会话；编辑会话只影响当前故事；创作对话则直接写入世界文件。

![世界编辑器中的世界基本信息和开场文本](/img/screenshots/roleplay/world-editor.png)

编辑器覆盖角色、地点与出口、物品、阵营、关系与知识、设定资料、剧情、变量和触发器。角色页还可配置声音、视觉身份、情绪、意图和日程；日程可按星期或世界的[日历规则](../world-format/calendar)限定。

世界本身的信息（名称、标签、规则、开场与其他开场、作者、版本标记、时区与起始时间）可在“关于”中编辑；版本标记会记录在由该世界开始的会话里。

界面页列出已编写世界携带的界面包：每个包要求什么、包含什么、每个问题出在哪个文件，并可预览每个界面位置在由这个世界开始的故事里的样子（见[界面包](./interface-packs)）。

日历页设置季节依据的半球和世界的节日：每个节日有标识、名称和所在的日子（与日常相同的[日期标记](../world-format/calendar)）。角色日常或触发器仍在引用的节日不能删除。没有节日且季节为北半球的世界不会有 `calendar.json`。

骰子页编辑世界的[骰子检定](../world-format/dice)（`dice.json`）：每个检定的使用场合、骰子、按总和还是按命中的骰子数读取、是否与难度或技能值比较、要加上的角色属性，以及结果区段。保存时会像故事开始时那样检查：骰子可能给出的每个数值都必须有区段，检定所加的属性必须是“追踪数值”中声明的关于角色的数值。删除最后一个检定会删除该文件。

工具页以开关的形式列出每一类智能体（主持人、角色、记录员）拥有的可选工具，保存在 `world.json` 中；故事以它们为起点，并可在自己的对话设置里更改。此版本不认识的工具会被保留，但不显示。同一页还在每一类智能体下折叠列出其他插件为所有人注册的工具（文件或命令行工具、MCP 服务器），它们在开启之前都是关闭的。

触发器页以句子的形式只读显示世界自行发生的事：每个触发器等待什么、做什么；在故事中还显示是否触发过、触发了几次，以及它提到了哪些世界里没有的东西。触发器通过创作助手创建和修改，或直接编辑 `triggers.json`。

保存前会验证数据。其他记录开始引用 ID 后应保持 ID 稳定；名称可以安全修改。外部文件变化不会持续监听，修改后需要刷新目录或编辑器。

角色编辑器把身份、角色类型、初始状态和较长的描述字段放在同一份可滚动表单中。

![可扮演角色的角色编辑器](/img/screenshots/roleplay/character-editor.png)

关系也可以先在图中查看，再编辑当前选中的连接。

## 翻译世界

世界以它被写成的语言进行：名字、描述和角色的说话都来自世界文件，与给模型的指令使用哪种语言无关。当编辑器发现世界使用的语言与你使用的语言不同，会在各个部分上方提示，开始故事的对话框里也会提示。世界所用的语言是根据文字的字符种类判断的，只区分英文和中文。

点击**翻译成……**会打开这个世界的创作对话，请它在原世界旁边生成一个用你的语言写成的**副本**。原世界不会被改动。副本是一个独立的世界：有新的 id、翻译后的名称，文件夹名是原文件夹名加上语言。

- 先统一翻译一次名字（人物、地点、物品、团体、节日），让每个文件对同一个对象使用相同的叫法。角色或阵营的原名会保留为别名，玩家仍可输入原名。
- 然后逐个文件翻译其中的文字：名称、描述、说话、目标、关系、设定资料、剧情、规则、开场、日程中的活动、触发器说的话，以及被追踪的变量的名称。
- 不是文字的内容原样保留：id、引用、时间、日期规则、`{character:key}` 这类标记、数字，以及变量的设置。图像提示（视觉身份）、世界自带的提示文件和界面包会原样复制；需要时请手动修改。
- 每条译文在被接受前都会检查：每段文本一条译文、花括号中的标记不变、没有仍然停留在原文语言。检查失败的文本会再请求一次；仍然失败则翻译停止，对话里会说明原因。
- 然后像开始故事时那样检查这个副本，发现的问题会列在对话里。

翻译需要几分钟，在对话的后台进行，使用创作对话的模型：本地模型能让世界留在你的电脑上，而大型在线模型翻译得更快、通常也更好。开玩之前请先读一遍结果：本地模型有时会把名字译得与你期望的不同。
