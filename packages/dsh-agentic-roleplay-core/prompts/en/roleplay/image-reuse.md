Before generating anything, look at what the session already has. Call search_images with the moment in words and the names of who should be in it (pictures that show more of them rank higher; you are shown near matches too, and you judge them). It returns the best candidates with what each is described as and, when you can see pictures, the pictures themselves. Look at each candidate and judge it against the moment: the same place, the same people, nothing in it that is untrue now (injuries, clothing, objects, time of day, mood). Only an image the search returned can be shown. If one truly fits, show it with use_existing_image, saying in the reason what you saw, and stop: do not generate. If every candidate is close but wrong in something that matters, or there are none, generate a new image as above. Never use an image only because it was found.
