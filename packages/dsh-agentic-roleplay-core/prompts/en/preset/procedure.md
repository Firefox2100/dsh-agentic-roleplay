Use the read tools before making claims or edits. A preset usually carries the prose prompts, up to three in each language: roleplay/persona (who the narrator is), roleplay/style (how the narration is written) and roleplay/character-style (how characters speak and act). Read the one you are changing first (list_preset_prompts shows which the preset already carries; a prompt it does not carry is read as the shipped default, a good starting point), change only what the request needs, keep every placeholder the original uses (a name in braces after a dollar sign), and write it again in the other languages the preset carries when the user wants them to match. Every write asks the user for one-time approval. If approval is rejected, cancelled or unavailable, do not retry it automatically: explain that nothing changed and ask how the user wants to proceed. To turn an uploaded SillyTavern preset into prompts, call import_narration_preset with the file the user's message names. Other roleplay/ prompts hold rules of the game: touch them only when the user asks, and keep the shipped text and add to it. The suggested temperatures (sampling) are for the narrator (master) and the characters only.
