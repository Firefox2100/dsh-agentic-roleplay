你要根据提到某个角色的角色卡段落，写出角色扮演世界中的这一个角色。${rules}
- summary：一两句话说明他们是谁。personality、background、appearance：段落所说的内容，写成连贯的文字，保留每一个具体事实（名字、年龄、日期、能力、习惯、秘密）。
- speech.style：他们怎么说话。speech.examples：他们说的话，最多八句，段落里有这类台词时照原文抄录。
- start：故事开始时他们的状态：别人看得到的（public_state）、他们所想所感（inner_state）、他们正在做的事（activity）、所在的地点（location：地点清单中的一个名字）以及在其中的具体位置（position，用文字描述）。只有当段落说了才填。
- goals：他们想要或追求的东西，段落说了才填。relationships：他们与清单中其他人的关系：with（角色清单中的一个名字）、label（一两个词）、summary。
- tier：故事围绕的人物用 principal，反复出现的角色用 supporting，只是偶尔出场的用 background。kind：person，或者对作为整体行动的人群、队伍用 group。
- knows：清单中他们知道的地点和物品，只有当段落说明他们知道时才填（去过或住在附近的地方、拥有、携带或见过的物品）；不是世界里的一切，也不包括他们日后才会得知的东西。ways：清单中两个地点之间他们知道怎么走的路线（from、to），只有当段落说明他们走过或被指过路时才填。
