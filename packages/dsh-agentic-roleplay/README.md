# @dsh-agentic-roleplay/all

The complete agentic roleplay bundle for DeepSeek Harness (DSH), maintained by Firefox2100.

It installs the roleplay UI and orchestration plugin, the persistent state service, and the DSH voice-input components used by the interface. AI models and media services are configured separately through [DSH AI Providers](https://firefox2100.github.io/dsh-ai-providers/docs/intro).

## Install

```bash
dsh plugin --profile <profile> add @dsh-agentic-roleplay/all
```

After installation, restart the profile and configure the roleplay storage root under **Settings → Role Play**.

This is an independent community project. It is not an official DSH package and is not maintained or endorsed by the DSH maintainers.
