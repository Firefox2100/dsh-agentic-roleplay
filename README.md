# dsh-agentic-roleplay

An agentic roleplay bundle for DeepSeek Harness.

## Packages

| Package | Role |
|---|---|
| `dsh-agentic-roleplay` | The bundle. Install this one. |
| `dsh-agentic-roleplay-core` | Plugin: roleplay UI, orchestration and storage. |

## Development

```sh
pnpm install
pnpm run typecheck
pnpm run test
pnpm run build
```
